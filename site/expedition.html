자동 구매 방식 자세히

균형은 약 4분 내 모을 수 있는 강화 비용은 저축하고, 그보다 비싼 목표가 성장을 막으면 작은 대체 강화를 먼저 구매해. 장기 저축은 종전 방식처럼 목표 비용이 모일 때까지 기다려. 유동형은 즉시 구매 가능한 강화를 우선해. 보급 의뢰는 모든 방식에서 해금된 최고 등급만 선택해. 4초마다 판단하며 유물 상자·환생·코어는 자동 처리하지 않아.

자동 구매 꺼짐
기존 저장 데이터에서는 자동 구매가 꺼진 상태로 시작해.

자동 보급 의뢰

의뢰는 최초부터 자동으로 반복되고, 완료 보상은 자동 수령돼. 의뢰를 강화하면 수익이 높아져.

유물 도감

5거리마다 획득하는 상자는 출처 거리에 따라 발견 가능한 유물이 달라. 15·25·30·40·45·50거리 목표를 격파해 얻는 상자에서 새로운 유물군이 열려. 유물은 귀환 후에도 남아.

유물 수집 진행도
원정 중 상자 개봉 자동화 · 직접 수령도 가능

기본 꺼짐 · 60초마다 모은 상자를 최대 20개 자동 개봉 (오프라인 정산 포함). 귀환과 코어 투자는 직접 선택해.

최근 발견 기록

아직 발견한 유물이 없어.

탐사 기록

2시간까지 오프라인 시간을 정산해. 이전 게임과 다른 저장 공간을 사용해.

플레이 검증 기록

60초마다 탐사 거리·용병 수·유물·강화 흐름을 이 기기에만 기록해. 접속 중과 오프라인 정산을 구분해. 자동 전송은 하지 않아.

직접 파일을 공유하면 2~3회차 성장 정체 구간을 함께 분석할 수 있어. 파일에는 플레이 기록과 수집 현황이 담겨 있어.

탐사 저장 데이터 백업·복원

단일 HTML 파일을 열거나 브라우저를 바꿀 때 저장 위치가 달라질 수 있어. 진행 상황 전체를 JSON 파일로 별도 보관할 수 있어.

복원하면 현재 용병단 탐사 기록을 덮어써. 이전 네온 방치단 게임 저장과는 별개야. 파일은 직접 선택하지 않는 한 외부로 전송하지 않아.

↻ 귀환 · 새로운 원정

10거리 지휘급 적을 격파하면 귀환할 수 있어. 더 깊이 탐사할지, 영구 코어를 챙기고 다시 출발할지 직접 선택해.

귀환과 영구 강화

10거리 보스를 격파하면 환생이 해금돼. 적 처치 거리마다 환생 성과를 조금씩 쌓고, 1개 미만은 다음 탐사로 이월돼. 처음 돌파한 거리의 보너스 코어는 한 번만 얻어. 코어가 1개 이상 모였을 때 귀환할 수 있고, 유물·지휘관 레벨·코어 연구는 남아. 용병·훈련·의뢰 강화는 초기화돼.

최근 귀환 결과

전투력 비교는 각각 훈련·소집 전의 기본 2인 편성이야. 코어를 추가 투자하면 현재 출발 전투력은 더 높아질 수 있어.
