# 독립 용병단 — 유물 조합 1차: 탐사 정보망 (2026-11-18)

## 왜 이 조합부터 구현했나
실제 플레이 2회 귀환 후 사용자 피드백은 **유물 획득이 수치만 증가시키고, 반복되는 탐사·전투의 모습은 바뀌지 않는다**는 것이다. 기존 15종을 단순 증가하기보다 수집 조합으로 **보상이 나오는 방식 자체**를 바꾸는 검증을 선택했다. 새로운 전투 버튼/반복 터치/최종 UI 고정은 하지 않는다.

## 획득 조건과 실제 작동
- 보유한 두 영구 유물 **탐사 일지(`scout`, 25거리 상자)** + **작전 통신기(`relay`, 30거리 상자)**가 각 1개 이상이면 **탐사 정보망** 활성화. 유물 보유 수에는 별도 소모나 재투자가 없다.
- 정보망이 활성화된 상태에서 **30거리 이후의 정예/보스 적 2개를 격파**할 때마다 자동 유물 조사를 한 번 실행한다. 한 탐사(귀환 전)당 **최대 2회**, 정보망 진행 상태는 저장·복원하고 귀환 시 초기화한다.
- 조사 보상은 **추가 행동 없이 즉시 획득**한다. 이미 보유한 **일반 상자·상자 깊이·FIFO 개봉 순서는 전혀 소모/변경하지 않는다**. 기존 일반 정예·보스 상자는 매 5거리마다 별도로 쌓인다.
- 유물 조사 보상 후보는 그때 격파한 **거리의 획득 가능 풀만** 사용한다. 미발견 유물 종류가 하나라도 있으면 **그중에서 새 종류를 100% 우선 발견**한다. 모두 발견했으면 아직 복제 상한에 도달하지 않은 기존 유물의 복제 1개, 해당 깊이 풀이 모두 상한이면 기존 수집 완료 크레딧 보상 방식 적용. 40/45/50거리 등 미래 풀을 앞당기지 않는다.
- `relicHistory`에는 발견 거리/유물/첫 발견/출처(`intel` 또는 기존 `chest`)를 구분해서 기록. 오래된 이력은 기존 상자 출처로 복원. 기존 코어/환생 혜택은 추가되지 않는다.
- 전투 장면에는 특별한 `intel` 큐가 발생하고, 그 순간 **탐사 정보망 · 새 조사 보상!** 표시. 유물 탭의 세부 기록에서 `조사 진행 0/2 또는 1/2`, `이번 탐사 최대 2회`, 자동 발견 수를 확인한다. 귀환 기록과 직접 내보낸 분석 JSON에도 이번 탐사의 획득 횟수가 남는다.
- 게임 엔진 `site/expedition-engine.js`에서 획득/상자/저장 처리. 임시 UI `site/expedition-field.js`·`site/expedition-ui.js`·`site/expedition-ui.css`에서 관전 및 상세 정보 처리. **현재 UI는 최종 확정이 아니므로 추후 전체 교체 가능**, 로직은 그대로 유지.
- 저장키 `neon_expedition_prototype_v1`, VERSION 1, 레거시 저장 `neon_rework_07`은 불변. 사용자 기존 2회 귀환 저장에 둘 다 있으면 즉시 활성화되며, 과거에 격파한 거리의 자동 보상을 소급해서 부여하지 않는다.

- `tests/expedition.test.cjs`: 단독 보유 0회, 조합 2회 격파 조건, 30거리 이후 제한, 추가 자동 발견과 일반 상자 동시 보관, 유물 도감 미발견 우선 선택/미래 깊이 제한, 최대 두 번 제한, 저장 중간 진행 및 과거 데이터 복원, 귀환 통계 계승.
- `tests/expedition-deep-run-relic-audit.cjs`: 기존 40/45거리 상자가 깊이 전용 유물의 *첫 획득 출처여야 한다*는 과거 가정은 자동 조사로 더 이상 항상 성립하지 않는다. 대신 40/45/50거리 유물의 **정당한 획득 깊이** 및 각 거리의 해금 보상 접근을 검증한다.
- 브라우저 `tests/expedition-browser.test.cjs`: 360/390/412px에서 임시 UI의 유물 도감 진행도/조사 출처 표시 및 전투 상시 표시와 저장 동작 확인.
- 30분 opt-in 균형 자동 구매 + 상자 자동 개봉 3시드 비교. 사용자가 두 유물을 **이미 보유했다고 가정해 효과를 분리**한 경우: 시드 123456789 기존 유물 8종→정보망 9종, 987654321 9→10종, 20261118 9→10종; 모두 정보망 자동 발견 1회, **도달 거리 40/40/40 및 코어 획득량 26/26/26 동일**. 두 유물을 미리 지급하지 않은 일반 조건에서는 세 시드 모두 기존과 같은 거리/종류/코어였다.
- 이 숫자는 **엔진 시뮬레이션**이며 사용자 실제 플레이에서 조합을 획득하는 시점과 즐거움은 검증하지 않았다.

## 장점과 위험 (미확정 콘텐츠)
- 장점: ① 유물 수집 조합 완성 자체가 새로운 목표 ② 발견 종류에 실질적인 영향을 주는 추가 자동 보상 ③ 추가 반복 클릭 없이 수집 재미 강화.
- 위험: ① 기본 유물 종류가 15종이라 두 번의 보상만으로는 장기 수집 한계 해결 불가 ② 30거리 이후 조건이어서 초기 회차에는 체감이 늦을 수 있음 ③ 새 종류 수집이 빠른 경우 후반 유물 부족을 더 일찍 느낄 수 있음.
- 따라서 지금은 유물 조합이 **실제로 작동하는 검증용 한 가지**로 유지하고, 새로운 적 전술·다양한 보상 선택지·장기 수집군을 추후 별도로 설계해야 한다.
