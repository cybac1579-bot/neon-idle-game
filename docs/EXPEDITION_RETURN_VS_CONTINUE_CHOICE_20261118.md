# 네온 방치단 — 귀환 vs 계속 탐사 선택 근거 (2026-11-18)

## 왜 이 단계를 진행했는가
- 장시간 전선 체류는 현재 1차 원형에서 관찰된 현상이다. 30분과 120분 실측 시드에서 도달 거리·코어 계산은 정상이나 최대 단일 교전 1,157초가 관찰되었다.
- 장기 교전을 강제로 단축하거나 대기 시간을 보상으로 바꾸면 탐사/환생 선택과 영구 유물 수집에 대한 동기가 약해질 수 있다.
- 따라서 현재 단계는 **플레이어가 귀환을 선택할 실질적인 근거를 정확하게 표시**하되, 새로운 자동 환생/자동 투자/추가 보상/딜 증가를 도입하지 않는다.

## 실제 구현 내용
- 엔진 `returnChoiceSnapshot(s)`는 비파괴·읽기 전용. 기존 `rebirthRewards(s)`, `coreCost(s,id)`, `relic(s,id)`, 영구 유물 해금 깊이, 기존 상자 출처를 사용한다. RNG를 호출하거나 상태·저장 값을 변경하지 않으며 예상 소요 시간을 발명하지 않는다.
- `귀환` 탭의 `#returnChoices`에 두 선택을 나란히 **내용상 비교(모바일에서는 세로 쌓기)** 한다. 메인 전투는 계속 보이고 관련 버튼이 추가되지 않는다.
  - **지금 귀환**: 실제 지급 확정 코어 수량, 귀환 후 기존 보유 코어를 합한 액수, 전선/보급 중 각 **다음 1레벨을 개별적으로** 구매 가능한지 여부 및 비용. 둘 다 살 수 있다는 약속으로 혼동하지 않도록 '또는', '각' 사용. 코어 투자는 플레이어 직접 선택.
  - **계속 탐사**: 지금 보관 중인 미개봉 상자 수(귀환 후에도 보존), 현재 상자에서 가능한 미발견 유물 종류 수, 이미 깊이를 해금했지만 아직 발견하지 못한 유물 수, 다음 새로운 유물 해금 거리.
- 영구 유물 도감의 55거리 신규 티어 설명도 반영.

## 보장·확률 표시 정확성
- 일반 깊이에서 새 유물이 반드시 나온다고 주장하지 않으며, 상자에 해당 깊이 미발견 유물이 *후보*로 존재하는 경우에만 가능 수를 계산.
- 깊이 15/25/30/40/45/50/55의 **해당 깊이 전용 첫 발견**이 실제 원형 드롭 로직으로 보장되는 상자가 보관 중이고, 그 유물이 아직 미발견 상태일 때에만 특별 보장 문구 표시.
- 기존 저장의 `chestDepths`가 없는 상자는 깊이 0으로 취급하며 실제 기존 드롭 풀인 최대 30거리로 계산. 이전 유물 드롭을 재굴림하거나 새 상자를 생성하지 않음.
- 영구 해금은 현재 탐사 단계가 아닌 **누적 최고 격파 거리 `best-1`** 기준. 환생 직후의 1거리와 이미 해금한 45거리의 목표가 혼동되지 않게 한다.
- 모든 유물 깊이를 개방했다면 새로운 깊이를 임의로 추천하지 않고, 미수집 후보만 표시.
