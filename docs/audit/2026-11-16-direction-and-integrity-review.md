## 새 오류/과거 오류/미검증의 구분
- **현재 HEAD 차단 오류:** GitHub Actions 3종은 모두 성공. 자동 테스트에서 새로운 미수정 실패는 확인하지 못함. 단, 테스트 밖의 실제 게임 오류가 없다는 뜻은 아님.
- **과거 실제 오류 수정 이력:** 구 저장 퀘스트 보관 초과분 소실, 비정상 스킬 LV80/100 복원, 자동환생 위상 목표 충돌, 보스 HP 재로드, 성장 스킬 카드 겹침은 코드/회귀·브라우저 차원에서 수정됨.
- **과거 하네스/검증 오류:** 배경 틱에 따른 크레딧 기대 오차, VM assert 누락, 무작위 스킬 카드 수 고정 가정 등이 수정돼 최신 PASS. Node 의존성 deprecation warning은 남아 있음.
- **아직 검증되지 않음:** 실물 Galaxy S25+ 30분 재미·가독성·터치·발열, 최대 2시간 오프라인 복귀 성능, 배포된 HTTP 자산 parity, 실제 사람의 높은 효율 최적 전략, 장기 위상 및 모든 코어 경로의 재미와 상한.

## 사용자 결정 필요 여부
- **지금 즉시 개발을 멈출 새 필수 의사결정은 없음.** 이전 확정 규칙대로 개선 진행 가능. 게임플레이 임시 실험인 STAGE20 스킬 선택, STAGE60 전선 지원, LV1~9 경험치 0.6배, 반응로 LV3+ ×1.3과 수동 3회 강화 선택은 사용자 확정 영구 규칙이 아니므로 1차 플레이본 실기 평가 후 유지/수정을 판단해야 함.
