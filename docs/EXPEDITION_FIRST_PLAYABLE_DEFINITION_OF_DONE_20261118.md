# 《네온 방치단》 1차 플레이본 완료 기준 · 2026-11-18

## 1차 범위: 30분 직접 평가 가능한 독립 모바일 원형

**완료란 정식 출시·콘텐츠 완결이 아니라**, Galaxy S25+ 세로 화면에서 사용자가 최소 30분 동안 실제 게임을 진행하며 재미, 전술 가시성, 성장/유물 수집/자발적 귀환의 동기를 평가할 수 있는 하나의 **플레이 가능한** 안정적 빌드를 제공하는 것이다. 이용자의 실제 즐거움은 CI만으로 증명할 수 없고 사용자 실기기 평가가 필요하다.

### 현재 1차에 포함하는 핵심 루프

1. 자동 전진 용병단(방벽병·척후사수·현장정비사)과 일반/돌격/교란/정예/보스 전투; 용병별 실제 개입, 재정비와 전투 가시성
2. 소집·훈련·크레딧 수급의 반복 의뢰; **선택형** 자동 구매, 기본은 꺼짐, 조작 없이 관전 가능
3. 5거리마다 보급 상자, 출처 거리별 유물군, 첫 발견/중복 성장, 영구 보유, 단독/조합 전술, 선택형 자동 상자 개봉
4. 전투 캐릭터와 별개인 지휘관 레벨·특성, **자발적인** 환생, 획득한 코어 투자와 다음 탐사의 다른 출발 상태
5. 30분 동안 탭 연타와 강제 환생 없이 진행 가능; 저장/복원/백업, 최대 2시간 오프라인 정산(중복 정산 금지)
6. 360/390/412px 모바일 브라우저와 독립 오프라인 HTML 빌드 확인. 단, 웹 Chromium 확인은 실제 Galaxy S25+와 별도 취급

### 1차에 **필수 아닌 것**

- 100거리 이상 도달, 3회 환생 및 전 유물 17종 완전 수집
- 완성 일러스트, 고해상도 애니메이션, 방대한 캐릭터/적 수, 콘텐츠의 장기 끝점
- 정확히 60분 경과 시 자동/강제 첫 환생; 자동 귀환 및 임의 난수 보상 보정
- 기존 `main` 공개판에 즉시 병합하거나 저장을 덮어쓰기

## 자동 기능 완료의 판단

**신규 독립 원형 기준** `tests/expedition-first-playable-gate.cjs`:
- 시드 3개 × 선택 자동구매 `balanced`/`adaptive` 2개 = **6회**의 30분 실제 엔진 진행
- 5분마다 사용자가 상자를 직접 개봉한다고 가정. 전투 탭 및 수동 성장 구매 0; 실제 유물 드롭 외 지급 없음
- 5/15/30분 진행·유물·성장 시점 기록; 30분 전 강제 환생 없음; 종료 후에만 자발적 환생을 실행해 영구 레벨/유물/최고 기록/코어 보유, 저장 복원을 검사
- 4시간 비활성 뒤 최대 2시간 오프라인 정산, 같은 시점에서 재정산하지 않는 중복 방지 검사
- 이것은 **기능의 최소 선별 게이트**다. 실제 사용자가 30분 재미있게 느낀다는 가정, 이상적인 환생 선택 시각, 실제 Android 배터리/브라우저 수명 주기를 검증하지 않는다
- 파일을 fast regression CI에 연결하여 엔진 변경이 이 최소 루프를 깨지 않는지 확인한다. 전체 모바일/오프라인 Playwright 검사는 `.github/workflows/integration-portrait.yml`을 따른다.

## 1차 ‘완료’ 선언의 추가 조건

1. 최신 동일 SHA에서 **엔진·저장 회귀·모바일 360/390/412px·오프라인 HTML 실행**의 실제 CI가 통과
2. 오프라인 플레이 파일 및 **전체 저장 JSON 백업·복원**이 사용자에게 사용 가능; 기존 프로덕션 저장과 별도
3. **실제 Galaxy S25+에서 30분 플레이 후** UI 잘림/오동작·일시 정지 후 재개·유물 확인·귀환/성장 피드백, 플레이 피로·관전 재미를 사용자 기준으로 확인
4. 치명적인 오류 발견 시 새 기능보다 수정 우선. 중요도 낮은 아트/추가 콘텐츠는 2차로 미룰 수 있음

현 시점 실제 Galaxy S25+ 직접 30분 검증과 즐거움 평가는 **미완료**. 위 자동 검사 성공만으로 최종 1차 완료를 선언하지 않는다.

## 60분 목표와 현재 환생 리듬의 충돌

기존 2026-11-14 구 설계는 최고 효율의 첫 환생 약 60분을 목표로 했다. 하지만 2026-11-17 이후 《환생용병단》 참조 방향으로 독립 구조가 변경되면서 **10거리 보스 격파 이후 귀환을 자유롭게 선택**하게 됐다. 현재의 실제 30분 엔진 시뮬레이션에서는 균형 자동구매 10거리 격파가 약 52~69초이고 첫 45거리의 무귀환 진행은 약 55분대인 조건도 있다. 게다가 25거리 조기 귀환과 코어/유물 재수집이 후속 45거리 진행을 더 빠르게 만드는 경우가 있다.

따라서 **첫 귀환을 무조건 60분으로 강제하는 것은 이 1차 평가 목표에 포함하지 않는다.** 사용자가 첫 귀환을 선택하는 자연스러운 순간이 언제인지, 30분의 재미와의 관계가 무엇인지 별도 실플레이 검증 후 정책을 결정한다. 기존 약 60분 성장감 목표를 폐기했다고 주장하거나 이미 달성했다고 주장하지 않는다.
