# 용병단 탐사 — 첫 돌파 코어 보상 및 귀환 게이트 (2026-11-18)

## 문제와 최소 수정 원칙
- 원형은 10거리 **도달만으로** 귀환 가능하여 거리 10 보스를 잡기 전에도 코어를 받을 수 있었다.
- 초입 짧은 귀환의 반복 코어 수익이 깊은 원정보다 크게 유리했다. 심층 유물은 15/25/30거리 보스 상자에서만 발견하도록 개편했지만, 최초 심층 도달의 코어 체감이 낮았다.
- **강제 대기 시간, 귀환 횟수별 무료 능력치, 반복 귀환 횟수에 대한 패널티를 추가하지 않았다.** 코어만 지급하고 사용자는 투자 여부와 방향을 직접 선택한다.

## 변경된 규칙
- 첫 귀환: **10거리 보스 격파 후** 가능. 상태상 `runBest>=11`이어야 한다(11거리는 10 보스를 클리어한 다음 전선).
- 반복 기본 코어 지급은 기존 식 유지: `max(1, floor(sqrt((runBest-5)/5)))`. 단, 위 첫 보스 격파 게이트를 충족해야 함.
- 최초로 보스를 격파한 거리 기준, 다음 기록 보너스 코어를 영구적으로 **각 1회씩** 지급:
  - 15거리 +1, 25거리 +2, 35거리 +3, 50거리 +5, 75거리 +8, 100거리 +13.
- 예시: 최초로 35거리 보스를 격파한 뒤 귀환하면 기존 기본 2코어 + 신규 최초 기록 누적 6코어 = **8코어**. 다음에도 35거리까지만 귀환하면 기본 2코어만 지급.
- 15거리에서 최초로 귀환해 +1을 수령했다면, 이후 25거리 최초 귀환에서는 새로운 25거리 기록 +2만 지급(15거리 기록 보너스 재지급 없음).
- 기록 확정은 **귀환을 직접 실행한 시점**이며, 전투 중 15/25/35에 도달해도 자동으로 코어가 지급되거나 귀환하지 않음. 기존 유물 및 플레이어 영구 레벨 유지.
- 기존 저장 파일에 `claimedBreakthroughDistance` 필드가 없으면 기존 `best-1`을 과거 기록으로 간주하여 소급 중복 보너스를 방지. 신규 저장 파일은 0부터 시작.
- 도감 귀환 메뉴에 기본 코어, 첫 기록 보너스, 총 코어, 다음 첫 돌파 목표를 별도로 표시. 확인 대화상자에서도 정확한 내역을 표기.

## 남은 한계와 다음 결정
- 짧은 반복 귀환의 코어/시간 효율은 여전히 더 높다. 심층에서는 새로운 유물군과 초기 돌파 보너스를 획득하지만 실제 선호는 플레이어 평가가 필요하다.
- **최적 플레이 기준 첫 환생 약 60분**이라는 과거 설계 목표를 이번 원형에 적용하지 않았다. 현재 첫 귀환은 약 1분으로, 기본 원정/병종/유물 구조가 검증된 뒤 성장 곡선 전체와 함께 조정할 과제로 남긴다. 단순 시간을 강제하는 방식 지양.
- 대량 유물/장비 또는 아트 제작을 앞당기지 말고, 다음에는 30분~2시간의 실제 선택 패턴 및 **초기 귀환 과다 반복 부담**을 확인한다.
- 모바일 실기(Galaxy S25+) 검증 전 main 병합 금지. GitHub CI 결과는 별도 확인할 것.
