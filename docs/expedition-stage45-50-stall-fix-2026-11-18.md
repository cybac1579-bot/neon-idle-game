# 《네온 방치단》 45~50거리 성장 정체 수정·재검증 (2026-11-18)

## 먼저 고친 문제
- 이전 검증에서 일반 균형 자동 구매는 **다음 최고 등급 호송 계약의 큰 가격이 모일 때까지** 훈련·소집조차 진행하지 않았다. 두 번째 탐사의 45~50거리에서는 **최대 2,960~4,455초** 동안 구매가 없었다(기존 적 체력 곡선, 재현 시드 3개).
- 40거리 이후 적 체력은 매 거리가 23.5%씩 증가하고 50거리 보스는 3.8배였다. 이 조합 때문에 강화 구매와 전투 진행이 모두 느려졌다.
- 단순히 계약 가격을 낮추는 시도는 더 높은 계약 레벨을 저축하느라 다시 정체되는 문제가 있었고, **적 체력만 낮춰도 긴 구매 대기는 남았다**. 두 원인이 독립적으로 존재한다.
- 따라서 새 보물·코어·스킬 추가 없이 **자동 구매 막힘**과 **지나친 적 체력 곡선**을 각각 고쳤다.

## 실제 수정
1. **균형 자동 구매**(`balanced`): 기존 훈련→소집→최고 등급 보급의 카테고리 순환은 유지. 목표 가격을 보유 크레딧과 현재 자동 보급의 초당 예상 수입으로 비교한다. 약 **240초(4분) 이내에 저축 가능한 목표는 저축**하고, 그보다 멀면 다른 카테고리의 구매 가능한 성장 중 원래 목표 가격의 **35% 이하**만 선행 구매한다. 실제 구매한 카테고리 다음부터 순환. 4초당 최대 한 건, 최상위 보급 등급 우선, 수동 상자·코어·귀환 규칙 동일.
2. **장기 저축**(`reserve`): 선택한 고등급 강화만 끝까지 저축하던 종전 방식을 명시적으로 별도 제공. 사용자가 경제 우선 전략을 원한다면 계속 선택 가능. 기본 자동 구매는 여전히 **꺼짐**이고 기존 `balanced` 저장 데이터는 일반 균형 모드로 이어지되 **긴 대기를 피하는 수정된 동작**을 적용한다.
3. 적 체력: **1~40거리 수치 변경 없음**. 그다음 거리부터 기본 지수 증가율을 매 거리 **23.5%→18%**로 완화. 보스 3.8배, 정예 2배는 유지. 예: 40거리 적 최대 체력 **185,669→185,669**(동일), 50거리 보스 **1,532,526→971,759**(약 36.6% 감소). 50거리 보스는 49거리보다 여전히 강함.
4. 메인·전투 화면에는 통계/버튼 추가 없음. 자동 구매 선택과 설명은 기존 용병 탭에서만 업데이트.
5. 기존 main 및 구 저장 키 변경 없음. 환생 횟수 자체 보너스 없음, 코어 수급·유물 드롭 변경 없음.

## 동일 최신 코드에서 4개 시나리오 분리 검증
고정 시드 123456789, 987654321, 20261118. 첫 원정 45거리 격파→수동 귀환→획득 코어를 전선에 직접 투자→두 번째 원정 50거리 보스 격파. 선택 자동 구매 ON; 5분마다 상자 개봉. **사람의 실제 플레이가 아닌 결정론적 엔진 시뮬레이션.**

| 조건 | 두 번째 50거리 보스 격파(초) | 45~50거리 최장 성장 구매 공백(초) |
|---|---|---|
| 종전 무제한 저축 + 이전 적 체력 | 10868 / 12987 / 12234 | 2960 / 4455 / 4320 |
| 새 균형 구매 판단 + 이전 적 체력 | 4655 / 4843 / 4520 | 759 / 671 / 628 |
| 종전 무제한 저축 + 완화한 적 체력 | 8681 / 10298 / 10363 | 2532 / 2456 / 2627 |
| **새 균형 구매 판단 + 완화한 적 체력** | **3722 / 3762 / 3635** | **432 / 420 / 420** |

이 조합에서는 막힘이 **약 49~74분 → 약 7분**으로 줄었다. 격파까지 걸리는 시간은 약 **61~63분**. 이 수치는 모든 전략의 진행 시간이 같아야 한다는 뜻이 아니며, 원정 중 달라지는 투자에 따라 더 차이가 날 수 있다. 자동 구매 방식이 바뀌면서 용병·훈련에 더 투자하는 것도 단축에 영향을 주므로 체력 변경의 효과만으로 설명하지 않는다.

새 균형과 유동형의 차이:
- 새 균형: 보급 계약 강화를 단기적으로 구매할 수 있으면 비용 저축을 존중. 이 테스트에선 2차 원정 호송 계약 LV.10.
- 유동형: 당장 살 수 있는 종류로 빠르게 순환. 2차 원정 호송 계약 LV.8~9.
- 장기 저축: 단일 고급 구매를 계속 모으는 기존 정책. 2차 원정 호송 계약 LV.13. 이 모드를 고른 경우 장시간 대기는 선택된 정책의 영향이 크다.

## 남은 확인
- 45~50거리의 정체를 **코드/수치 시뮬레이션에서 완화했지만**, 실제 사용자 입장에서 7분의 성장 공백을 재미있게 느낄지는 검증이 필요하다.
- 현재 최초 귀환은 10거리에서 훨씬 이르게 가능하다. 과거 '최적 첫 환생 60분' 목표를 이 작업으로 달성했다고 주장하지 않는다.
- 50~60거리 및 3차 원정의 코어 대비 난이도/반복성은 이번 수정 후 재측정이 필요하다. 사용자의 직접 평가 전에는 main에 병합하지 않는다.
