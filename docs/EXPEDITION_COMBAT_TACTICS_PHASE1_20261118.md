# 독립 용병단 — 정예 측면 조준 / 호위 반격 전술 실험 (2026-11-18)

## 사용자 목적과 실험 범위
- 실제 2회 귀환 플레이에서 "유물 수집이 숫자만 바뀌고 하는 일이 똑같다"는 지적이 있었음. 지난 회차에는 `탐사 일지 + 작전 통신기` 수집 조합으로 **보상 동작**을 바꿨으나 전투 상대와 용병 행동 변화가 부족했음.
- 이번은 **첫 적 전술 + 첫 대응 유물 조합** 수직 슬라이스. 모든 적에게 종류와 전술을 다수 추가했다거나 콘텐츠 문제를 해결했다고 주장하지 않는다.
- 기존 임시 UI를 최종 디자인으로 확정하지 않으며, 전투를 관전하면서 성장을 조작하는 원칙은 유지.

## 작동 규칙
- 적 전술: **15거리 이후 정예/보스**가 살아서 전투가 최소 3초 진행되고 살아 있는 후열 용병이 전장에 있을 때 2초 동안 **측면 조준**을 예고. 예고 후 **단 1회**, 기존 적 공격량 중 일부를 후열에 집중한다. 공격 자체는 무작위가 아니라 재현 가능한 상태 기반 패턴이다.
- 측면 집중 타격도 기존 HP 비율 상한 적용. 기존 적 DPS를 **재분배**할 뿐 증가시키지 않고, 전투 난수 소비도 늘리지 않는다. 15거리 이전/일반 적 및 후방 대상이 없는 전투에는 새로운 불필요한 타격을 발생시키지 않는다.
- 유물 조합: 영구 유물 `호위 계약서(guard, 5거리)` + `초점 조준기(archer, 15거리)`를 동시에 보유하고, 살아 있는 방벽병·척후사수가 현장에 있을 때 조준 공격이 발동하면 **방벽병이 타격을 대신 흡수**, **척후사수 자동 반격**을 1회 발동한다. 원래 초점 조준기의 3번째 정밀 사격과 별개의 대응 동작.
- 반격 유효 피해: 척후사수 기본 한 발의 약 절반(현재 성장 배율 포함), 남은 적 체력 이상을 기록하지 않음. 대응 횟수/추가 유효 피해를 `relicEffects.flankShots/intercepts/counterDamage`에 기록. 코어/일반 상자 획득량과 확률은 그대로.
- 누구나 **추가 버튼·타이밍 입력 없이** 대응한다. 유물 조합이 없다면 후열 집중 타격은 정상 발생하나 HP 제한이 있어 기존 성장 난이도를 무너뜨리지 않게 한다.
- 경고·타격·호위 반격을 임시 전장 시각화 `site/expedition-field.js`의 상태 기반 배너·전투 큐로 표시한다. CSS는 독립 `site/expedition-ui.css`; 일러스트/실제 애니메이션은 이후 교체 가능. 유물 상세 탭에서 부족한 유물과 이번 탐사 호위 반격 수를 선택적으로 확인한다. HUD 과밀 방지.
- `enemyTactic`은 `stage/elapsed/phase/windup/used/flash/result`로 현재 적의 조준 상태를 유지. **중간 저장 후 2초 경고가 다시 시작되거나 사라지지 않게** 복원하고, 적 격파/귀환 시 새 적의 상태를 초기화한다.
- 이전 `neon_expedition_prototype_v1` 저장에는 `enemyTactic`이 없을 수 있어 해당 적에서만 초기 상태로 복원. 과거 행동 카운트는 소급하지 않는다. 새 실행 횟수는 귀환 기록 스냅샷에 유지하고 현재 탐사 통계만 초기화한다. 기존 `neon_rework_07` 및 공개 `main`과 무관.

## 구현 파일
- `site/expedition-engine.js`: 경고 상태, 피해 대상 전환, 조건부 호위 반격, 통계 기록, 저장 정규화.
- `site/expedition-field.js`: 게임 상태 기반 경고 배너와 특수 전투 큐.
- `site/expedition-ui.js`: 호위 조합 해금 상태/유물 도감/귀환 통계(선택 조회).
- `site/expedition-ui.css`: 교체형 임시 시각 연출.
- `site/expedition-app.js`: 플레이 분석 JSON에 새 효과 카운터만 추가.
- `tests/expedition.test.cjs`: 2초 경고, 1회 타격, 조합 유/무, 후열/전열 피해 분배, DPS 보존, 조준 중 저장·귀환 회귀.
- `tests/expedition-browser.test.cjs`: 360/390/412px 실제 브라우저에서 전장 경고/반격 배너가 엔진 결과를 반영하는지.
- 실제 유물 수집·환생·추가 보상은 종전 규칙대로.

## 30분 및 120분 비교 검증 (엔진 시뮬레이션)
- 이전 커밋 `92eef98e64a83e04c43ef63d8bfb8561fe22c050` 대비 신규 엔진; 3개 시드 × (기존 보유 유물 그대로 / 조합 유물 두 개 인위 보유) × 30/120분 총 12쌍. 명시적으로 자동 구매 균형 + 자동 상자 개봉을 켠 자동 탐사, 수동 성장/귀환 입력 없음.
- **30분**: 모든 6쌍의 최종 거리와 코어 획득량 동일. 미보유 3쌍은 신규 정예 타격 6회·호위 반격 0회, 조합 보유 3쌍은 신규 타격 6회·호위 반격 6회, 반격 총 유효 피해 약 70~76.
- **120분**: 6쌍 모두 기존과 같은 최종 거리(미보유 53/53/51, 보유 53/53/54), 코어량도 동일. 정예 타격 8회, 조합 보유 시 호위 반격 8회. 실제 수동 플레이의 시각적 인지/적정 조작 부담은 **미검증**.
- 보유 유물 2개를 강제로 지급한 조건은 유물 획득 난수/희귀도를 시험하는 것이 아니라 **조합 자체의 효과**를 분리한 것이다. 자동 구매 모드 이외의 전략, 장기 고레벨 전투, 실제 Galaxy S25+ 체감은 후속 대상.
