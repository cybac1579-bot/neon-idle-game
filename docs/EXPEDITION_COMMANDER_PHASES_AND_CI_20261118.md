# 네온 방치단 — 지휘급 적 반복 전술 및 2026-11-18 CI 정리

## 구현 목적과 범위
- 기존 15+ 정예/보스는 교전 3초 이후 **측면 조준을 1회만** 수행. 40~50+ 후반 장시간 보스 전투에서는 행동 공백이 커짐.
- 40거리 이후 정예·보스가 살아남는 경우, 처음 측면 조준과 후열 집중타격 이후 **36초 간격으로 전열 압박(방벽병 돌진) → 측면 조준을 번갈아 수행**. 조준 단계는 1.5초(전열)/2초(후열).
- 기존 **합금 배지 + 진군 북** 조합은 전열 압박을 막고 자동 반격; **호위 계약서 + 초점 조준기** 조합은 후열 측면 공격을 막고 자동 반격한다.
- 별도 버튼·새 영구 유물·직접 공격 입력은 추가하지 않았음. 기존 전투 전체 DPS 예산, 적 보상 및 코어 공식은 전술 추가 자체로 변경하지 않음.
- 적별 `enemyTactic`에 `turns/nextAt/move`와 귀환 요약 `relicEffects.commandMoves/commandSurges`를 저장. 과거 세이브에 없는 값은 안전한 기본값/후속 사이클로 이행. 귀환 후 발동 횟수는 초기화하되 직전 귀환 통계는 보존.
- 공개 `main`은 건드리지 않았으며 신규 원형은 `integration/reconcile-main-redesign-20261114`에서만 변경.

- 기존 돌격병까지의 코드 `d863a560cd3f04b454d478a060a2130347c9814d`를 기준으로 30분/120분, 3시드, 자연 수집/조합 선보유 조건 = **12쌍(24개 플레이)**. 전투 탭 입력/자동 환생 없음, 균형 자동 구매+60초 자동 개봉 사용.
- 30분 **자연 수집 3시드 합계**: 신규 반복 지휘 행동 **27회**, 그중 전열 압박 **14회**. 120분 누적: 신규 반복 지휘 행동 **162회**, 전열 압박 **83회**. 같은 세 시드의 원거리 교란은 각각 12회/17회.
- 120분 자연 수집 3시드 전투 시간은 총 21,600초, 이 중 보스 전투 **5,385초**. 최장 단일 적 교전 **1,157초**. 따라서 지휘 패턴은 장시간 관전 변화를 주지만 **모든 종류의 장기 교전 공백을 해결하지는 못함**.
- 12쌍에서 기존 코드 대비 최종 단계·귀환 예상 코어·발견 유물 종류는 각각 **차이 0**. 이는 지정 시드·자동화·길이에 한정하며 실기 플레이 재미 증명은 아님.
- 레벨·귀환 밸런스 및 신규 추격 신호기 효과는 별도 독립 검증으로 진행 중. 지휘 행동 간격 36초, 추가 대응 반격의 효과는 향후 테스트 데이터를 바탕으로 조정 가능.
