## 통합 방법 판단
- **권장**: 최신 main에서 새 통합 브랜치를 분기하고, 기존 그래픽 브랜치에서 **CSS/DOM 및 시각 전용 코드만** 필요한 단위로 이식. main의 게임 계산/저장 코드는 유지.
- **비권장**: 현재 그래픽 브랜치를 그대로 main에 덮어쓰거나 main을 무검증 병합. 자동화 main 개발이 계속되므로 통합 시작/검증 시점의 main SHA를 고정해야 함.
- 통합 브랜치에서 기존 main 회귀 검사 + 그래픽 브라우저 검사 + 저장/로드/오프라인/재구성 회귀 검사를 모두 실행한 뒤, 실제 30분 플레이용 미리보기로 제공. 본배포 전 사용자 승인.
- 원화 이관은 별도 에셋 등록 작업으로 분리해 추적. 이미지 파일 등록/실제 렌더 성공 전까지 완료 처리 금지.
