- **중간에 나온 CI 실패는 게임 자체의 데이터 손실이 아님.** 새 테스트가 한 번 누르면 1명만 소집된다고 가정했고, 이후 전선 화면의 최대 3명만 표시하는 제한을 실제 보유 인원 전체로 착각했다. 테스트를 실제 묶음 구매와 후방 인원까지 합산하도록 고쳤고, 최종 동일 코드 CI가 성공했다.
- R1/R3의 기존 완료를 최신 `3187dafcc8e5` 시험판에 대해 재확인했고, Galaxy S25+ 실제 `file://` 저장 정책/30분 체감은 별도로 미검증이므로 **추정 준비율 약 90%, 남은 R4~R6 세 작업**을 유지한다. 실제 플레이 피드백 없이 R4/R5 완료 처리 금지.
- Android 실제 플레이에서는 처음 실행 후 저장 백업 JSON을 만들고, 중간에 다른 앱으로 전환 후 복귀하여 2시간 오프라인 한도 처리·저장 지속을 확인해라. 자동 저장 경고가 나오면 새로고침 전 전체 저장 JSON을 다운로드해라. `내 플레이 기록 JSON`은 분석용이고 `전체 저장 백업 JSON`은 복원용이라는 차이를 유지한다.

## 1차 이후

- 실사용 결과를 보고 유물 종류·효과·전투 상호작용과 반복 환생의 신선도 확장.

- 신규 원정/장기 콘텐츠·복잡한 고급 시스템은 1차 합격 이후 단계적으로 추진. 다만 `main` 공개판 병합과 정식 출시를 1차 평가 조건으로 만들지 않는다.
