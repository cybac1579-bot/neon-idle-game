# 네온 방치단 — 품질 게이트·오류 재발 방지 및 시스템 개편 기준
기록일: 2026-11-14
상태: 운영 원칙 확정 / 자동화 구현 및 검증은 미완료

## 역할과 책임
- 사용자: 실제 플레이, 재미·취향·방향 판단, 이상 현상 공유. 개발 지식이나 재현 절차 작성 의무 없음.
- AI 개발 담당: 설계·구현·수치 밸런스·기능 정합성·영향 분석·자동 시뮬레이션·회귀 검증·저장 호환성 책임.
- 사용자 피드백은 현상·발생 시점·직전 행동·스크린샷 중 가능한 것만 받는다. 추가 정보를 요구하기 전에 가능한 자동 재현부터 수행한다.
- 기능 테스트 통과와 게임 시스템 검증 통과를 절대 혼동하지 않는다. 실제 인간 플레이 검증과도 구분한다.
- 새 기능 추가보다 발견된 오류의 근본 원인 수정과 재발 방지 검증을 우선한다.

## 필수 개발 게이트
1. **변경 영향 명세**: 변경 시스템, 의존 시스템, 불변 조건, 기대 성장 범위, 저장 데이터 영향, 테스트 범위를 코드 변경 전에 기록한다.
2. **기능·경계·불변 조건**: 중복 보상 없음, 음수/NaN/Infinity 없음, 해금 조건 보존, 신규 최고 기록 초과 스테이지 무단 스킵 금지, 연구/특성 상한, 재구성 초기화/보존 계약 등.
3. **시스템 연계 테스트**: 전투↔경제↔레벨↔특성↔장비/스킬↔심층↔재구성↔위상↔자동화↔저장. 각 변경의 직접·간접 영향 검증.
4. **실제 로직 기반 다중 전략 자동 플레이**: 무구매/최소 조작/최저가/경제 우선/공격 우선/상위 강화 우선/혼합/재구성 최적화; 고정 난수 시드 + 복수 시드. 테스트 정책이 실제 사용자 전략을 완전히 대변하지 않음을 명시.
5. **성장 관측 지표**: 5·15·30분, 2·10시간의 스테이지, 최고 클리어 기록, 영웅 레벨·XP·미사용 특성점, 크레딧/에너지, DPS, 장비/스킬, 심층 층·결정·연구 구매율, 코어·재구성 횟수·강화 소진율, 위상, 정체 구간, 이전 기록 복귀 시간. 게임 시간을 가속하되 실제 시간 단위 step과 동등성 확인.
6. **기준과 경보**: 하드 불변 조건 위반은 실패. 성장 속도·정체·소진 속도 이탈은 경고/실패 범위를 사전 합의한 기준으로 판정. 의도적 가속과 비정상 폭증을 구분하며 숫자 상한을 근거 없이 임의로 정하지 않는다.
7. **이전 버전 비교**: 같은 초기 상태·전략·시드로 기준 버전과 새 버전 비교. 변경 의도와 관계없는 시스템의 급격한 편차는 조사.
8. **회귀 테스트**: 발견된 오류는 재현 가능한 최소 테스트 추가 후 수정. 테스트가 실제로 실패를 탐지하는지 고의 결함 주입/뮤테이션 테스트로 확인.
9. **저장 호환성**: 신규/기존/부분 손상 세이브, 리로드, 탭 숨김·복귀, 오프라인 정산, 재구성·위상 경계, 자동화 동작을 검증. 마이그레이션과 롤백 경로 준비.
10. **결과 판정**: 기능·통합·성장·저장·브라우저/모바일·인간 플레이를 각각 통과/경고/실패/미검증으로 보고. 실패하면 수정 후 관련 게이트 재실행. 실행하지 않은 검사는 성공 보고 금지.

## 오류 처리 프로세스
현상 접수 → 코드/실행으로 재현 → 근본 원인 → 유사 원인·영향 범위 조사 → 수정 전 실패 테스트 → 근본 수정 → 회귀/연계/성장/저장 검사 → 결과 및 미검증 범위 보고.
작은 변경은 영향 범위 테스트+짧은 시뮬레이션, 핵심 공식/재구성/저장 변경은 전체 장기 시뮬레이션. 10시간 게임 시간은 실제 10시간 대기가 아닌 가속 시뮬레이션.

## 확인된 결함·구조 위험(개편 백로그)
P0: 경험치 획득 지수 증가(1.08^stage) vs 필요 XP 다항 증가(level^1.45)로 레벨·특성 폭증 가능.
P0: 스테이지 스킵이 재구성 횟수만 따르며 이전 클리어 기록 밖의 신규 구간까지 건너뜀. 스킵 기능 삭제 금지: 과거 클리어 구간만 전투력 조건에 따라 고속 돌파, 최고 기록 근처 감속, 신규 구간은 1단계 진행. 보스·보상·해금·기록 의미 보존.
P0: 최고 기록 s.best는 실제 클리어가 아닌 도달 단계도 기록함. 과거 클리어 기록과 현 회차 진행 상태 분리 필요.
P0: 코어/재구성 배율과 스킵의 복합 가속, 영구 강화 조기 소진, 장기 성장 곡선 미검증.
P0: 심층 탐험은 선택·사건·보상이 주로 수치 변형이며 장비·스킬·특성·재구성과 전략적 연결이 부족. 층·연구·자동 탐험의 목적 재설계.
P0: 테스트가 기존 구현의 동작을 정답으로 가정하거나 단순 finite/기능 동작만 확인하여 구조 결함을 놓침. 자동 플레이 정책과 실제 사용자 전략 차이 존재.
P1: 경제/에너지/전투 업그레이드의 선택·효율 불균형, 자동 구매의 최저가 고정, 장비·스킬의 조합 부족, 위상 전환 후 목표 부족, UI 정보 과밀, 저장 마이그레이션 위험.
검증된 사실과 설계상 위험을 구분하고, 확인하지 않은 실제 기기·재미 문제는 단정하지 않는다.
