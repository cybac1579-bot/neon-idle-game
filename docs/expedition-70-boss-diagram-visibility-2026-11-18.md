# 《네온 방치단》 70거리 전술 가시성 검증과 전장 도해 이펙트 보호 (2026-11-18)

## 목적과 기존 CI
직전 기준 커밋 `7000007e`의 저장·복원, 빠른 엔진, 첫 귀환 밸런스, 세 번 원정, 모바일 브라우저 통합 검사가 모두 성공함을 GitHub Actions에서 직접 확인했다.

65거리에서 획득하는 고유 유물 「전장 도해」는 70거리 이후 보스/75거리 이후 정예에게 체력 75% 이하 시 1회 최대 HP 6% 타격을 가한다. **기능 발동과 플레이어가 화면에서 효과를 읽을 수 있는 것은 별개**이므로, 새 유물이나 보너스를 더하기 전에 실제로 전술이 가려지는지 점검했다.

## 실제 엔진 관찰: 전술은 발동하지만 단발 이벤트는 사라질 수 있다
엔진 `tick(1)`로 고정 시드 `123456789`, 자동 구매 `balanced`, 300초마다 상자 수동 개봉을 시뮬레이션. 실제 플레이어가 각 45/50/60/65거리 목표 후 **직접 귀환**, 모든 획득 코어는 전선 강화에 투자하고 마지막 70거리 보스를 관찰했다.

- 실제 70거리 교전 **939초 (15분 39초)**.
- 같은 보스와 싸우는 동안 지휘 전술 추가 전환 **24회**, 적 전열 압박 **12회**, 완전 돌진 저지 **12회**, 후열 호위 반격 **13회**, 정밀 사격 **3,037회**, 전장 도해 균열 타격 **1회**를 집계했다.
- 전장 도해 발동 약 **302초 시점**에 실제 유물 카운터가 1회 증가했지만, 해당 1초의 최종 `battleEvent.type`은 `fallen`(방벽병 후퇴)이었다. 따라서 그 프레임만 렌더하면 **유물 공격은 성공했는데 다른 이벤트가 마지막 이펙트를 덮는다**.
- 다른 경로(시드 `20261118`, `adaptive` 자동구매, 60초 자동 상자 개봉)의 약 289초 지점에는 마지막 이벤트가 `diagram`으로 남았다. 고정된 모든 조건에서 숨겨진다는 뜻이 아니며, 렌더 타이밍에 따라 불규칙하게 보일 수 있다는 증거다.
- 반복된 전술 횟수는 많아도 15분 이상 기다리는 보스에 특별히 새로 등장하는 전장 도해는 **딱 한 번**이다. 이 가시성 수정이 전투의 긴 대기를 해결한다고 해석하면 안 된다.

위 값은 게임 엔진의 합성 반복 실행 기록이지 Galaxy S25+에서 사람이 실제 화면을 본 결과가 아니다.

## 실제 구현: 발동 후 4초간 기존 전술 띠로 확인
- `site/expedition-engine.js`: 적별 `enemyTactic.diagramFlash`를 표시 전용 4초 카운터로 추가. **실제 전장 도해 1회 발동 때만** 4로 설정한다. 일반 타격/용병 후퇴 이벤트가 `battleEvent`를 덮더라도 별도 상태를 보존한다.
- 매 `tick()`에서 카운터를 감소시키므로 모든 용병이 쓰러져 전투 함수를 끝까지 실행하지 못해도 **잔여 표시 시간이 정상적으로 만료**된다.
- `normalize()`에서 구 저장에 없으면 0, 현재 저장에는 최대 4로 복원한다. 전술 발동 여부 `diagramTriggered`, HP, 데미지, 상자/드롭, 지휘관·코어 등은 그대로. 저장 버전과 키도 바꾸지 않음.
- `site/expedition-field.js`: **기존 좁은 `enemy-intent` 영역**에 「전장 도해 · 약점 균열 타격 발동」을 짧게 유지한다. 별도 HUD나 버튼을 추가하지 않고 **새로운 적 공격 예고(windup)가 발생하면 그 경고를 최우선**으로 표시한다.
- `tests/expedition-stage65-diagram.test.cjs`: 저장 후 유지, 다른 `fallen` 전투 이벤트와 공존, 전원 후퇴 중에도 4초 종료, 옛 저장에서 없는 이벤트를 만들지 않는 회귀 검사 2개 추가.
- `tests/expedition-browser.test.cjs`: 360/390/412px 세로 화면에서 실제 전장 표시를 검사. 발동 직후 외부의 `fallen` 이벤트를 덮어씌워도 전장 도해 문구가 보이는지, 즉시 적 돌진 예고로 바꿨을 때 경고가 우선되는지 검증한다.

## 잔여 문제 및 개발 우선순위
1. 70거리 보스 15분대 교전은 여전히 길다. 이번은 **전술 피드백 가시성 복구**이며 난이도/성장 경제 조정이 아니다.
2. 전술 표시가 읽힌다고 해서 보스전이 재미있다는 결론은 내리지 않는다. 여러 유물의 실제 누적 피해 및 장기 교전 공백을 분리하여 측정할 필요가 있다.
3. **최적 첫 귀환 약 60분 목표는 여전히 미충족**. 초반에 효율적인 조기 귀환과 깊은 유물 수집 가치의 상충 문제를 손대지 않았다.
4. 최신 전체 모바일 CI 완료 여부는 별도 확인한다. 엔진 단위검사 통과와 실제 모바일 플레이 체감을 혼동하지 않는다.
