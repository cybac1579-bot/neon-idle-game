### 플레이 기록 전달 방법 (기기 내부 저장)

1. 테스트본을 모바일 세로 화면에서 열고, 상단 **통계** 탭으로 이동한다.
2. 기록을 새로 시작하고 싶다면 **플레이 기록만 초기화**를 눌러 확인한다. 게임 세이브는 초기화되지 않는다. 완전히 새 게임부터 30분을 시험하려면 게임 초기화도 별도로 실행해야 하며, 필요한 기존 진행은 보존/백업에 주의한다.
3. 평소처럼 **30분 정도 실제 플레이**한다. 기록은 플레이 중 이 기기의 브라우저 저장 공간에만 보관된다. 자동 서버 전송 없음.
4. **통계 → 플레이 기록 JSON 내보내기**를 누른다. `neon-playtest-YYYY-MM-DD.json` 파일이 내려받아진다.
5. 이 대화에 그 JSON 파일을 첨부하고 지루했던 구간, 좋았던 보상 또는 화면/조작 문제를 함께 알려 준다. 그러면 STAGE별 경과시간, 구매·퀘스트 행동 집중도, 장비·스킬·코어 선택, 오프라인 복귀를 실제 데이터 기반으로 분석할 수 있다.

**주의:** 기록은 브라우저·도메인별 로컬 데이터라 저장 공간/시크릿 모드/브라우저 변경 시 사라질 수 있다. 기록은 최대 최근 1,200건의 이벤트와 합계 카운터만 유지한다. 이 JSON에는 플레이 경과 및 게임 내 선택, 기록 시작 시간이 포함되므로 사용자가 선택해서 공유한다. 자동 전송과 계정/기기 식별 정보 수집은 구현하지 않았다.

**검증:** 실제 Chromium 휴대전화 세로 크기에서 버튼 누름→구매·퀘스트 수령·STAGE 변화→JSON 다운로드→새로고침 후 기록 유지→기록 초기화 시 세이브 보존을 검사하여 통과했다. 다만 실물 Galaxy S25+ 30분 플레이·실사용 UX·백그라운드 장시간 복귀는 별도 사용자 검증이 필요하다. **첫 환생 경제/퀘스트 보상 수치 변경은 실제 플레이 기록 분석 전까지 보류한다.**
