## 권장 30분 플레이 관찰

필수 사전 설정 없이 모바일 세로에서 게임을 열고 평소 하던 것처럼 플레이한다. 가능하면 아래 네 가지만 간단히 메모한다.

1. **처음 10분:** 캐릭터와 적 전투가 화면에 잘 보이는지, 강화 버튼과 다음 목표가 어디인지 바로 이해되는지
2. **20분:** 반복 구간에서 무엇을 기다리고 있는지, 스킬·장비 보상이 기억에 남는지
3. **30분:** 실제 도달 STAGE, 반복 조작이 부담이었는지, 30분 더 플레이하고 싶은지
4. **예외 상황:** 화면 잘림·터치 불가·저장 소실·백그라운드 복귀 멈춤·심한 발열·갑작스러운 게임 리셋이 있으면 그 현상만 기록

**검증 완료와 미완료를 분리한다.** GitHub 단위/Chromium 화면 테스트는 통과했지만, 이 Vercel 시험용 URL의 보호된 실제 HTTP 페이지 로딩, Galaxy S25+ 실기기 테스트, 30분 플레이 재미, 안드로이드 장시간 오프라인 복귀 성능은 아직 검증되지 않았다.
