# 《네온 방치단》 심층 첫 귀환 → 2차 탐사 및 50거리 보스 재현 검증 (2026-11-18)

## 이번 판단의 목적
35~50거리의 길어진 성장 대기와 신규 40/45거리 유물이 **귀환 후 실제로 더 빠른 원정**에 기여하는지 확인한다. 유물 도감의 수집 재미를 훼손하는 강제 시간 게이트나 자동 귀환은 도입하지 않는다.

## 시뮬레이션 조건
- 저장소: cybac1579-bot/neon-idle-game
- 단일 기준 브랜치: integration/reconcile-main-redesign-20261114
- 엔진이 제공하는 균형 자동 구매를 사용자가 명시적으로 활성화한 것으로 가정. 저축형 balanced 및 유동형 adaptive 각각 비교.

- 획득한 코어 중 구매 가능한 전부를 플레이어가 **전선(valor)**에 직접 투자한다고 가정(세 시드·두 모드에서 첫 귀환 60코어, 전선 코어 9단계).
- 자동 귀환, 자동 코어 사용, 자동 상자 개봉은 없는 원형. 2차 원정은 **50거리 보스를 실제 격파**할 때까지 진행.
- 본 결과는 결정론적 모의 엔진 테스트. 사용자 실제 플레이/가장 효율적인 전략을 증명하지 않는다.

## 첫 번째 vs 두 번째 원정

| 모드 | 1차 45거리 격파 시각(초) | 2차 같은 45거리 격파(초) | 2차 50거리 보스 격파(초) |
|---|---|---|---|
| 저축형 균형 | 8648 / 7332 / 8805 | 4463 / 5417 / 5133 | 10870 / 13358 / 12243 |
| 유동형 균형 | 3662 / 3507 / 3810 | 1937 / 1917 / 1830 | 4777 / 4610 / 4719 |

- 45거리 재격파 시각은 **두 모드, 세 시드 모두 단축**. 같은 모드라도 난수·유물·연구/소집 투자 조합에 따라 절약 폭이 다르다.
- 50거리 보스는 **유동형 2차 원정 약 77~80분**, 저축형 2차 원정 약 181~223분에 격파. 기존 저축형은 보급 의뢰 상위 투자에 더 집중해 전투 성장이 상대적으로 늦을 수 있다. 시간을 강제로 평준화하면 투자 정책의 의미가 약해질 수 있다.
- 50거리 최초 격파에 따른 신규 기록 코어 **+5**는 실제 격파한 이후 귀환 화면에서 반영. 자동 지급/귀환 없음.
- 2차 50거리 완료 시 기본 격파 적립 코어 95 + 첫 50거리 기록 보너스 5 = 100코어(이번 비교 조건). 코어는 추가 귀환을 사용자가 선택해야만 수령함. 이는 장기 경제 인플레이션 검토 대상이며, 이번 단계에서 무작정 하향하지 않았다.

## 새 깊은 유물 효과의 실제 기여
- 40거리 선발권 묶음, 45거리 훈련 규정집은 각 1개 기준 각각 소집·훈련 비용 **6% 감소**.
- 비교를 위해 45거리 귀환 직후 저장 상태를 복제하여 신규 2종만 없는 경우도 가정(2차 원정 중 새 상자 개봉을 제외한 별도 모형).
- 유동형 2차 45거리까지 신규 2종을 유지했을 때 **2059 / 2158 / 2239초**, 신규 2종을 제거했을 때 **2109 / 2174 / 2268초**. 차이 50 / 16 / 29초.
- 저축형은 신규 2종에 따른 단축이 같은 실험에서 0 / 5 / 15초에 그침. **영구 성장 전체의 약 절반 속도 단축을 새 유물 2종의 효과라고 주장해서는 안 된다.**
- 보상은 원정 재료 가격의 장기적 부담을 줄이는 보조적 성격. 신규 유물 수집의 심리적 보상이 충분한지는 플레이 경험 검증 필요.

## 이번 기능 및 검증
- 신규 테스트 tests/expedition-deep-second-run-audit.cjs: 3시드×2자동 구매 정책, 실제 1차 45거리 격파→직접 귀환→코어 투자→2차 50거리 격파; 영구 유물 계승·귀환 보너스·격파 시각과 자동 귀환 방지 검증. 기존 저조작 CI에 연결.
- site/expedition-app.js: 유물 도감의 이번/직전 5·10·15·25·35·40·45·50거리 격파 시간과 상대 변화(단축/증가) 표시. 비교할 기존 기록이 없는 경우 %를 꾸며내지 않음.
- site/expedition.html: 좁은 세로 화면에서 비교 정보가 화면 밖으로 넘치지 않도록 **도감 구역에만** 그리드·줄바꿈 적용.
- tests/expedition-browser.test.cjs: 40거리 50% 단축, 45거리 50% 증가, 50거리 보스 항목 표시 및 가로 오버플로 회귀 테스트.
- 기존 게임/저장 키 보호, 통합 브랜치에서만 작업. 주의: 첫 귀환 자체는 여전히 약 1분 만에 가능함. 이 실험은 **의도적으로 45거리까지 돌아가지 않은 원정**을 비교함.

## 아직 해결하지 않은 과제
1. 45→50거리에서 단순 비용 저축/장시간 전투로 인한 간격은 아직 길다. 몬스터 HP 조정이나 무분별한 신규 보물 종류 확대 전, 플레이어가 얻는 정보·보상 및 의사결정 시점을 점검한다.
2. 50거리 이후 코어 누적 곡선과 반복 환생의 선택 효율은 따로 검증. 환생 횟수별 자동 보너스는 금지.
3. 모바일 Galaxy S25+ 세로 실플레이 검증과 실제 UI 정보량 평가 이전에는 main 병합하지 않는다.
