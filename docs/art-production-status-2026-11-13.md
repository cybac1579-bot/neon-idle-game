## 판정
- **시각적 방향은 잠정 선정**, 최종 사용 가능한 신규 고해상도 원화 파일은 **없음**.
- 현행 `site/hero_swordswoman_219.webp`는 219px급 저해상도 **임시 이미지**이며 신규 원화로 간주하지 않음.
- `site/seha_portrait.webp`와 보스 WebP는 저장소의 기존 에셋일 뿐, 신규 판타지 주인공 원화로 확정하지 않음.
- 이전에 생성한 판타지풍 시안은 **화면 구도/복장 참고용**이며, 분리된 투명 배경 캐릭터 원화 또는 레이어 아트가 아니다.

## 실측 브라우저 화면 확인
- GitHub Actions run `43438487059` 통과, 스크린샷 `battle-compact-portrait.png` 확인.
- 390px 폭 세로 화면에서 검정/금색 UI와 전투 공간 확보는 확인했지만 주인공이 **매우 흐리고 작게** 보이며, 적은 기존 기계형 SVG다.
- 따라서 **브라우저 검사 통과 ≠ 원화 품질 확보**. UI/구도 작업과 원화 제작은 별도 완료 기준으로 관리한다.

## 유지해야 할 원칙
- `main`과 자동화 작업은 별도이며 수동 개편은 `development/reference-redesign`에서만 진행.
- 고해상도 원화가 없으면 기존 저해상도 이미지를 임시로 유지하되, 완성이라고 표현하지 않는다.

## 추가 시안 평가 (2026-11-13, 신규 생성)
- 검정·금색 갑옷의 금발 여성 검사, 고딕 성채 배경, 슬라임 적, 금색 공격 이펙트와 성장 패널을 한 장에 표현한 **통합 화면 시안** 생성.
- **미채택 사유:** 가로 화면 비율이고 UI·인물·적·배경이 단일 평면 이미지에 합쳐져 있어 세로형 모바일 게임에 바로 사용할 수 없음. 시안에 표현된 일부 기능/수치는 실제 구현 기능으로 간주하지 않는다.
- **활용 범위:** 갑옷 질감, 판타지 색감, 인물 묘사 수준, 골드 테두리 UI 참고.
- **다음 실제 작업:** 세로형 화면에 맞춘 투명 배경 전신 캐릭터 에셋을 별도로 제작·검수하고, GitHub 파일로 반영한 다음 실제 게임 화면을 캡처해 비교한다.

## 캐릭터 제작 시트 (추가 작업)
- 금발·보라색 눈·검정/금색/보라색 갑옷의 동일 캐릭터를 전신, 표정 9종, 작은 전투 포즈, 공격 효과로 구성한 시트를 생성.
- 디자인 일관성을 평가하는 **참고 시트**로 분류. 생성 결과는 단일 합성 이미지이며, 체커보드/회색 배경이 실제 투명 알파 채널을 의미하지 않는다.
- **게임 적용 상태: 미적용.** 개별 이미지 추출, 실제 알파 투명도 검증, 잘림 검사, 세로 화면 크기 확인, GitHub 에셋 업로드, 실제 브라우저 렌더링 확인이 남아 있다.
- 다음 우선순위: 전신 전투 기본 포즈를 단독 투명 배경 파일로 제작하여 이미지 크기/알파/외곽을 검증하고, 기존 임시 주인공 파일을 교체하는 방식으로 단계적 통합.

## 신규 전신 원화 후보 (추가 회차)
- 금발/보라색 눈/검정·금색 갑옷/보라색 망토/검을 가진 전신 단독 이미지 후보를 생성.
- 세로형 단독 캐릭터 구도는 이전 가로 통합 시안보다 게임 에셋에 가깝지만 **배경색/그라데이션이 남아 있어 알파 투명 배경 조건을 충족하지 않음**.
- 현재는 **시안 후보**로만 취급하며 게임 파일 교체나 플레이 가능 원화 적용을 주장하지 않는다.
- 다음 관문: 알파 채널이 있는 단독 PNG/WebP 확보 → 가장자리 잔상/검/망토 잘림 확인 → 모바일 전투 화면 합성 테스트 → 최종 채택 여부 결정.

## 실제 투명 배경 전신 후보 검증 (후속 회차)
- 신규 이미지 생성 후 실제 PNG 알파 채널 확인: RGBA, 1122×1402px, 완전 투명 픽셀 553,158/1,573,044.
- 게임용 WebP 후보를 로컬에서 약 448KB로 변환하여 검증. **완전한 투명 배경은 확인했지만** 검 끝과 망토가 이미지 경계에 닿아 있어 외곽 여백 보완이 필요함.
- GitHub에 원화 바이너리를 올리는 기능이 현재 연결 도구에 없어서 **개발 브랜치의 실제 에셋 교체는 아직 하지 않음**. 원화 생성·검증과 실제 코드 적용을 구분.
- 원본 PNG는 대화 파일 산출물이며, 이 문서만으로 바이너리 원화를 복원할 수 없음. 별도 에셋 업로드 후 게임 적용 및 브라우저 검증 필요.
