# 판타지풍 원화 제작·적용 상태 (2026-11-13)

## 판정
- **시각적 방향은 잠정 선정**, 최종 사용 가능한 신규 고해상도 원화 파일은 **없음**.
- 현행 `site/hero_swordswoman_219.webp`는 219px급 저해상도 **임시 이미지**이며 신규 원화로 간주하지 않음.
- `site/seha_portrait.webp`와 보스 WebP는 저장소의 기존 에셋일 뿐, 신규 판타지 주인공 원화로 확정하지 않음.
- 이전에 생성한 판타지풍 시안은 **화면 구도/복장 참고용**이며, 분리된 투명 배경 캐릭터 원화 또는 레이어 아트가 아니다.

## 실측 브라우저 화면 확인
- GitHub Actions run `43438487059` 통과, 스크린샷 `battle-compact-portrait.png` 확인.
- 390px 폭 세로 화면에서 검정/금색 UI와 전투 공간 확보는 확인했지만 주인공이 **매우 흐리고 작게** 보이며, 적은 기존 기계형 SVG다.
- 따라서 **브라우저 검사 통과 ≠ 원화 품질 확보**. UI/구도 작업과 원화 제작은 별도 완료 기준으로 관리한다.

1. 주인공: 정교한 판타지 애니메이션풍 여성 검사. 검정·금색을 중심으로 금속 장식과 명확한 실루엣, 과도한 네온 광원 배제.

3. 전투 기본 자세에서 검과 발끝이 잘리지 않도록 전신 확보. 390px 세로 화면에서 얼굴이 식별되는지 검증.
4. 부분 애니메이션은 기본 전신 원화 채택 **이후** 머리카락/의상/무기 광원을 별도 레이어로 제작. 현재 HTML 슬롯은 준비돼 있으나 파일은 없다.

## 유지해야 할 원칙
- `main`과 자동화 작업은 별도이며 수동 개편은 `development/reference-redesign`에서만 진행.
- 고해상도 원화가 없으면 기존 저해상도 이미지를 임시로 유지하되, 완성이라고 표현하지 않는다.

## 추가 시안 평가 (2026-11-13, 신규 생성)
- 검정·금색 갑옷의 금발 여성 검사, 고딕 성채 배경, 슬라임 적, 금색 공격 이펙트와 성장 패널을 한 장에 표현한 **통합 화면 시안** 생성.
- **미채택 사유:** 가로 화면 비율이고 UI·인물·적·배경이 단일 평면 이미지에 합쳐져 있어 세로형 모바일 게임에 바로 사용할 수 없음. 시안에 표현된 일부 기능/수치는 실제 구현 기능으로 간주하지 않는다.
- **활용 범위:** 갑옷 질감, 판타지 색감, 인물 묘사 수준, 골드 테두리 UI 참고.
- **다음 실제 작업:** 세로형 화면에 맞춘 투명 배경 전신 캐릭터 에셋을 별도로 제작·검수하고, GitHub 파일로 반영한 다음 실제 게임 화면을 캡처해 비교한다.
