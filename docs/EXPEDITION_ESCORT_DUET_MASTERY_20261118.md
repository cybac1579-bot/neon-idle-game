# 네온 방치단 — 중복 유물 2인 호위 협공 (2026-11-18)

## 목적
- 기존 40거리 이후 지휘급 적은 후열 집중 조준 → 전열 압박을 반복한다. 호위 계약서 + 초점 조준기 **각 1개**만 수집하면 단독 후열 차단/자동 반격이 활성화되고, 이후 중복 복제는 기본 수치 개선에 그친다.
- 기존 유물 16종과 발견/드롭 확률을 늘리기 전에 **기존 두 유물의 반복 수집 자체가 실제 전술 행동도 바꿀 수 있는지** 단 하나의 제한된 숙련 규칙으로 검증한다.
- 원작 플레이의 자율 방치/관전 중심을 보존하며 연타, 새 클릭 버튼, 새 전술 전용 재화, 자동 귀환을 도입하지 않는다.

## 실제 구현: 호위 협공
- `site/expedition-engine.js`: 스테이지 40거리 이상인 정예/보스가 **후열 집중 공격(flank)**을 실행하고, 호위 계약서 `guard >= 2`, 초점 조준기 `archer >= 2` 보유 및 공격 가능한 생존 척후사수 2명 이상일 때 기존 측면 차단을 **호위 협공(intercept-duet)**으로 바꾼다.
- 기존 1개씩의 호위 반격은 사수 반격 기본 계수 **0.5배**. 조건 달성 시 **0.75배**, 즉 반격 1회에 한정하여 기존보다 `+0.25 × 사수 기본 반격 기준량`만 추가. 적 남은 HP를 초과한 피해를 통계로 더하지 않으며 기존 일반 사격 DPS/병종 소집/경제/귀환 공식은 변경 없음.
- **40거리 이전, 사수 1명뿐인 편성, 사수 1명 후퇴 중, 둘 중 어느 유물이 1개만 남아 있는 경우** 기존 호위 반격이 유지된다. 전열 압박/돌격 방어/원거리 교란은 해당 조합이 아닌 기존 효과를 유지한다.
- `relicEffects.intercepts`는 실제 후열 차단의 개수 그대로, `relicEffects.counterDamage`는 실제 반격 유효 피해 그대로, 별도 `relicEffects.escortDuets`는 협공 조건으로 발동한 횟수만 집계한다.
- `site/expedition-field.js`: 실제 협공 시 기존 전투 이펙트 영역에 `호위 협공! 2인 연계`와 피해량 표시. 별도 상시 HUD 버튼 없음.
- `site/expedition-ui.js`: 유물 도감/전술 통계에서 `guard/archer` 각 2개 목표, 숙련 달성 상태, 발동 횟수 안내. 귀환 직전/직후 기록 및 5회 이력에서 확인 가능.
- `site/expedition-app.js`: 본인이 직접 내보내는 로컬 플레이 테스트 JSON에 `escortDuets`와 지휘 전술 관련 지표 추가. 자동 전송 없음.
- `nextRelicCopyPreview`는 두 번째 사본이 실제로 조합을 완성시키는 경우에만 `40거리 이후 사수 2인 호위 협공 해금`을 안내한다. 다른 복제를 과장하지 않는다.

## 저장 호환
- 기존 `SAVE_KEY`, `VERSION`, 귀환 구조, 16종 유물 상한, 코어 지급/재투자 정책 변경 없음.
- 구형 저장에 없는 `escortDuets`는 0으로 시작하며 **과거 발동 이력을 복원한 것처럼 만들지 않는다**. 이벤트 타입 `intercept-duet`은 저장/복원 allowlist에 정식 편입.
- 귀환 시 현재 탐사 `escortDuets`는 0으로 초기화, `latestReturn.relicEffects`와 `runHistory[].relicEffects`에는 관찰한 횟수를 보존한다. 본 수치는 환생 혜택을 추가하지 않는다.

## 아직 증명하지 못한 것
- 협공이 **수집의 장기 재미**를 충분히 높이는지는 사용자 실기 관전 테스트로만 판단할 수 있다. 이 변경은 특정 중복 조합에 *하나의 전투 동작 차이*를 추가한 실험이며, 전체 수집 완료 이후 새 유물 종류가 없는 한계를 해결하지 않는다.
- 협공 추가로 장기 누적 플레이 경제가 변하는지 확인할 때는 **실제 자동구매/실제 보상/출처별 드롭**이 포함된 30분/120분 시뮬레이션과 대조해야 한다. 인공 편성 단일 교전의 수치만으로 전체 밸런스 안정이라고 주장하지 않는다.
