# 《네온 방치단》 65거리 이후 새로운 수집 목표 — 전장 도해 (2026-11-18)

## 실제 엔진에서 재현한 문제
고정 시드 123456789·20261118, 자동 구매 balanced/adaptive, 원정 45→50→60→65→70거리, 매 구간 수동 귀환 뒤 획득한 코어를 전선에 투자하는 탐사를 재현했다.
- 기존 고유 유물 16종은 55거리에서 종류 해금이 끝난다. 비교한 4개 시드/구매 경로에서 65→70거리까지 **영구 유물 종류는 더 이상 증가하지 않았음**.
- 최신 65거리 정예전 HP 보정으로 65거리 체류시간은 줄었지만, 기존 70거리 보스 교전이 **944~1,009초(약 15분44초~16분49초)** 걸렸다.
- 기존 유물의 중복 복사본은 계속 늘어도 새로운 종류를 발견하는 목표가 끊겼다. 게임 화면에 신규 HUD 버튼을 붙이거나 수동 탭 전투를 도입할 필요는 없다.

## 실제 추가한 유물 — 전장 도해
- **고유 유물 17번째 종류, cap=1, 65거리 해금**. 엔진 `RELICS` 카탈로그에 한 종만 추가.
- 65거리 정예 격파 뒤 획득한 **거리65 출처 상자**에서 아직 미수집이면 확정적으로 발견한다. 이미 보유한 '탐사 일지 + 작전 통신기' 조합의 기존 자동 조사도 거리65에서 정상적으로 해당 유물을 찾아낼 수 있다. 공짜 지급/자동 개봉 강제는 없음.
- 효과: 70거리 이상 지휘급 보스 또는 75거리 이상 정예 적이 **체력 75% 이하**가 되면 한 전투에서 **단 한 번** 최대 체력의 6% 추가 타격. 현재 적 체력보다 더 큰 피해를 허위 집계하지 않음.
- 화면에서는 기존 `combat-cue` 영역을 재사용해 「전장 도해! 균열 타격」을 보여준다. 별도 전투 버튼·통계 HUD 없음. 도감과 귀환 기록에 사용 횟수 및 유효 피해를 기록.
- 기존 1~69거리 전투, 상자 개봉 확률 공식, 65거리 이하 적 체력, 보스 체력·드롭 확률·코어/귀환 규칙·기존 자동화 기본값은 그대로. 새 유물을 갖지 않은 모든 이전 저장은 0개로 복원.
