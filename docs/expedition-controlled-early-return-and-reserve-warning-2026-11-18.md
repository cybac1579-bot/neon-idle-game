# 《네온 방치단》 조기 귀환 보상 원인 분해 및 장기 저축 대기 안내 (2026-11-18)

## 이유 없이 초반 코어를 하향하지 않는다
지난 회차의 초반 비교는 직접 귀환할 때까지 모은 상자를 즉시 개봉하는 반면, 귀환하지 않는 대조군은 5분마다 개봉해 보상 효과를 누리는 시점이 달랐다. 이번에는 양쪽 모두 **5거리마다 상자 1개 획득 시 즉시 수동 개봉**하고, 5분 체크인에도 남은 상자를 개봉하는 동일한 정책을 적용했다. 자동 개봉을 실제 게임에 추가한 것이 아니라 **가상의 플레이어 수동 조작을 같게 만든 시뮬레이션**이다.

기준: 난수 시드 123456789 / 987654321 / 20261118 × 자동 구매 balanced/adaptive. 첫 원정에서 45거리 적을 실제 격파하기까지 시뮬레이션 경과시간. 조기 귀환은 15거리 또는 25거리 격파 직후 한 번만 직접 선택. 핵심 비교를 위해 조기 귀환 후 코어 **미투자**와 **전선에 투자**를 따로 구분했다. 기존 레벨·유물 영구 계승은 유지.

- **조기 귀환의 이점은 실제로 남아 있지만 코어만의 효과가 아니다.** 15거리 귀환 1회는 5거리 상자를 총 **12개** 개봉하고, 25거리 귀환은 **14개**, 무귀환은 **9개** 개봉한다. 중복 탐사에서 추가로 수집한 영구 유물의 강화가 일부 속도 차이에 기여한다.
- 15거리/25거리 조기 귀환한 뒤 코어를 **사용하지 않아도** 더 빨라지는 시드가 있는 반면 더 느려지는 시드도 있다. 그래서 조기 귀환 속도 차이를 전부 초반 코어 지급으로 돌리면 부정확하다.
- 코어 투자 시 균형 25거리 귀환은 2793~3244초, 유동 25거리 귀환은 2398~2826초. 무귀환 대비 더 빠른 경우가 여전히 많다.
- 최초 환생을 10거리 직후로 강제 권장하지 않고, 반대로 60분까지 잠그지도 않는다. 현 시스템에서는 첫 귀환의 **최적 타이밍이 약 60분**이라는 예전 목표가 달성되지 않았다. 유물 수집 자체가 빠른 반복 원정의 중요한 동기이므로 **첫 코어 단가·돌파 보너스만 일괄 하향하는 임의 조정은 보류**.
- 이번 검증은 유물 종류/효과까지 정확히 고정한 반사실 시험이 아니라, 주어진 게임 규칙에서 사용자 조작 조건을 공정하게 맞춘 비교다. '미투자' 조건은 코어 효과만 없앨 뿐 영구 레벨/유물 계승은 유지한다.

## 먼저 해결한 실제 선택 혼란: 장기 저축 모드
앞서 추가한 `reserve`는 **최고 등급 보급 의뢰를 위해 수십 분을 기다리는 것을 허용**하는 명시적 전략. 경제를 우선하는 사용자 선택 자체를 무시하고 무단으로 구매 방식을 바꾸지 않는다. 하지만 구매가 멈춘 이유를 모르면 엔진 오류처럼 느껴지므로 아래를 수정했다.

- `site/expedition-app.js`의 **용병 탭 > 자동 구매 상세**에서 `reserve`가 켜져 있고 목표 강화가 아직 비싸면, 잠금 해제된 보급 의뢰의 초당 보급 수입을 계산해 저축에 10분 이상 걸릴 때 예측 대기를 안내.
- 예시 문구: `보급 수익만 가정하면 약 40분 대기(전투 보상 제외) · 성장이 멈춘 것 같다면 균형/유동형 전환 가능`. 실제 숫자는 크레딧·의뢰 레벨에 따라 변경됨. **전투 크레딧은 제외**한 수치이므로 고정 ETA나 정확한 실제 대기 시간이라고 주장하지 않는다.
- 경고는 엄격 저축이 켜진 상태에만 표시하며, 균형/유동형으로 전환하면 사라진다. 설정·저장 구조와 자동 구매 우선순위는 그대로. 사용자 의사와 무관한 모드 강제 변경·자동 환생·코어 투자·자동 상자 개봉 없음.
- main/전투 HUD에는 새 버튼·통계 추가 없음. 좁은 모바일 세로 화면에서 장문의 안내가 가로로 튀어나오지 않는지 기존 통합 브라우저 회귀 검증에 포함.

## 미해결 및 다음 판단
1. **첫 귀환 최적 플레이 약 60분** 목표와 **반복 조기 원정+유물 수집 재미** 사이 설계 상충이 있다. 두 목표를 동시에 만족시키는 상자 획득 메커니즘이나 귀환 자원 투자 대안을 설계·검증하지 않은 채, 시간 게이트/초반 코어 하향을 시행하지 않는다.
2. 엄격 저축을 골랐을 때 50거리 보스가 여전히 길다. 이는 선택 전략이 전투 투자보다 경제에 치중한 결과. 사용자에게 실제 기다림의 원인을 알려주고, 이후 재시작/전략 변경 선택이 가능한지 확인한다.
3. 이번 개발은 규칙 변경이 아닌 **공정 재검증과 명시적 경고**. 조기 귀환의 효율 격차 자체가 해결됐다고 과장하지 않는다.
4. 실제 Galaxy S25+ 세로 플레이 검증 전에는 `main`에 병합하지 않으며, 공동 개발 브랜치는 `integration/reconcile-main-redesign-20261114`만 사용한다.
