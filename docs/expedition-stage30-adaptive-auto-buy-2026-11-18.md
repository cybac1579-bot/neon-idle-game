# 탐사 자동 구매: 30~35거리 성장 공백 분석 및 유동형 균형 원형 (2026-11-18)

## 실제 원인
- 첫 탐사, 균형 자동 구매 ON, 수동 성장 구매 없음, 5분마다 보관 상자 개봉, 3개 시드 비교.
- 기존 균형 모드는 훈련→용병→최고 등급 보급을 순환하되, 선택한 항목의 돈이 부족하면 더 싼 다른 강화도 무시하고 비용을 모음.
- 30~35거리에서 보급 계약 강화 가격이 약 14,629 → 23,846 → 38,868 크레딧으로 올라간다. 그동안 훈련이나 용병 소집을 살 수 있음에도 한 종류의 계약을 위해 대기하는 시간이 길어짐.
- 최장 연속 성장 자동 구매 부재 구간: 시드별 **447 / 291 / 307초**. 30→35거리 격파 시간은 **759 / 623 / 678초**, 총 성장 구매는 6 / 9 / 6회.
- 이 구간에서 전투 진행 자체는 지속하지만, 강화 선택이 막힌 채 누적 자원이 쌓이는 문제가 있다. 따라서 적 HP만 올리는 방향은 부적합.

## 신규 선택형 모드
- 기존 기본값 `balanced`(저축형 균형): **동작 변경 없음**. 선택한 종류의 비용을 모으고 다음 강화 대상을 바꾸지 않음.
- 새 `adaptive`(유동형 균형): 4초마다 현재 순서의 강화가 비싸면 다음 종류의 **구매 가능한** 훈련/소집/보급을 탐색. 실제 구매한 종류 다음부터 재순환.
- 보급 카테고리에서는 해금된 **최고 등급 의뢰만** 대상. 더 낮은 의뢰로 몰래 내려가서 사지 않음.
- 구매 가능한 강화가 아무것도 없으면 기존처럼 순서상 원래 대상 비용을 모음. 상자 개봉, 영구 코어 사용, 특성 투자, 자동 귀환은 어떤 모드에서도 자동화하지 않음.
- 모드 선택은 명시적인 사용자 입력이며, 기존 저장 파일은 현재 모드/ON·OFF를 유지. 신규 저장은 기존 기본 균형 및 자동 구매 OFF 유지.
- 용병 탭 안에서만 정책 선택 및 다음 구매/대기 상태 표시. 메인 전투 화면 UI 추가 없음.
