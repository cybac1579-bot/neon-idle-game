# 네온 방치단 — 16종 유물 1→2→최대 중첩 실측과 도감 개선 (2026-11-18)

## 확인 목표
2026-11-18의 36회 실제 엔진 탐사/3회 귀환 실측에서 45→50→55 경로의 3회차는 각 시나리오 모두 **신규 1종, 중복 약 10개**를 획득했다. 따라서 중복이 단순한 숫자 증가인지, 실제로 전투·성장 가치를 만드는지 항목별로 확인했다. 타깃은 복제 중첩 시스템의 의미와 정확한 사용자 안내이며 **기본 전투/귀환/보상 리듬의 임의 수정이 아니다**.

## 검증 조건과 한계
- 실제 `site/expedition-engine.js`를 호출하는 `tests/expedition-relic-copy-impact-audit.cjs`, 단독 GitHub Actions `expedition-relic-copy-impact.yml` 추가.
- 같은 부대(방벽병 4·척후사수 3·현장정비사 2, 훈련 7, 보급 업그레이드 동일)에서 각 유물의 **0개 → 1개 → 2개(최대1 고유 유물은 제외) → 최대 수집 상한**을 비교한다.
- 지표: 일반 전장 화력, 50거리 보스에서 실제 공격, 60거리 보스 체력 절반 이하 화력, 최대체력/방벽병 HP, 정비사 회복량, 보급 퀘스트 수익, 소집/훈련 비용, 일반 적 격파 경험치/크레딧, 중복 발견 추가 크레딧, 사수 세 번째 사격의 실제 추가 피해.
- 상시 버프와 특정 편성·시점 전용 효과를 구별해야 한다. 특히 `boss` 유물은 일반 `partyDps`가 아닌 **실제 보스 타격**으로 측정, `pursuit`은 **60거리 이상 보스가 체력 절반 이하인 상황**을 측정. 유물이 있어도 사수/정비사가 없거나 특별한 적 공격이 없으면 모든 상황에서 같은 효과를 체감하지는 않는다.
- 같은 시험에서 중복 가능한 **14종 모두 두 번째 복제 효과가 적어도 한 개의 적절한 지표에서 변화**를 만들었고, 고유 유물 **원정 연대기·추격 신호기 2종은 상한 1개**다. 이는 **14종이 매 복제마다 신규 행동을 해금한다는 뜻은 아니다**. 소유 조합의 자동 호위·돌격 저지·역통신 반격 등은 주로 **최초 조합 완성**에 의해 켜지고 복제는 주로 효율을 높인다.

## 두 번째 복제의 변화 예시
- 용광로 문장: 한 개 보유 시 대비 일반 화력 **+7.407%** (추가 피해량 비율). 진군 북/작전 통신기는 각각 **+4.762%**.
- 합금 배지: 기존 한 개 대비 부대 최대체력 **+9.091%**, 호위 계약서: **방벽병 HP +16.667%**.
- 교역 인장: 동일 보급 퀘스트 수익 **+10.714%**.
- 재생 결속선: 현장정비사 회복력 **+15.254%**. 별도 전투 후퇴 타이머에 대한 효과는 조건부.
- 균열 렌즈: 실제 보스 공격 피해 **+12.281%**. 일반 적에는 적용되지 않는다.
- 초점 조준기: 세 번째 사격의 **추가 피해량 45% → 90%**. 원정 편성 전체 DPS는 약 **+8.433%**. 첫 획득 때 사격 주기가 바뀌지만 두 번째 복제에 새로운 추가 사격 회차는 생기지 않는다.
- 탐사 일지: 경험치 추가 보정 **+15%p**, 중복 해체권: 중복 발견의 추가 크레딧 **75 → 150**, 선발권 묶음/훈련 규정집: 소집/훈련 비용 감소.
- 위 비율은 위에 적은 동일 시험 편성·기존 1개 보유 기준이다. 모든 플레이 상태에 그대로 적용되는 보편 증가율이 아니다.

## 3회차 실제 중복 유물의 용도별 분포
- `tests/expedition-three-run-relic-discovery-audit.cjs`를 확장해 **상자 중복**과 **탐사 정보망 중복**을 분리하고, 첫 발견/중복/상한교환이 전체 복제 수와 정확히 대조되도록 검증했다.
- [3회차 중복 구성 재실측 성공 #44244382759](https://github.com/cybac1579-bot/neon-idle-game/actions/runs/44244382759) · [36회 데이터 JSON](https://github.com/cybac1579-bot/neon-idle-game/actions/runs/44244382759/artifacts/14400574677).
- **45→50→55** 경로, 3시드 × 균형/적응형 자동 구매 = 6회, 3회차 평균 **신규 유물 1종, 상자 중복 10개, 정보망 중복 2개, 총 중복 12개**. 일반 상자 개봉만 세었을 때의 기존 평균 10개와 모순되지 않는다.
- 이 12개 중 평균 **화력 4.33개 / 체력·회복 3.17개 / 경제 3.83개 / 경험치 0.67개**. 유물들은 서로 다른 효과를 가지고 있으며 이 값은 개수의 용도별 분포이지 변화량을 동등하게 가중한 화력 비교가 아니다.
- **25→45→50** 경로 3회차는 평균 상자 중복 9개 + 정보망 중복 1.67개 = **총 10.67개**, 신규 발견 1.33종. 어떤 중복이 의미 있는지는 편성·특성·실제 적 종류에 따라 달라진다.
- 결론: 중복 12개가 모두 새 전술을 만들어주지는 않으며, 반복 수집을 사용자가 느끼도록 하려면 **무조건적인 중복 확률 인상보다 해당 복제의 실제 능력치 변화를 도감에서 보여 주는 것**이 우선이다.

## 게임 내 가시화
- 엔진 `nextRelicCopyPreview(s,id)`: **실제 현재 저장값을 읽는 비파괴 계산**. 일반 화력/체력/보급·소집·훈련은 현재 편성·현재 구매 단계의 엔진 함수를 호출하여 현재값과 추가 1개 값을 보여준다. 보스·사수·지휘관 경험치·중복 보너스는 해당 상황에만 적용되는 보정을 명시한다.
- 소지한 복제 가능 유물의 도감 카드에 `다음 1개 효과 · 현재값 → 다음값` 문구 추가. **수집 상한**과 **고유 유물 중복 불가**를 구별해서 보여준다. 유물 미발견 카드는 기존대로 이름과 효과가 잠겨 있으며, 전투 화면은 그대로 유지.
- 추가 효과가 조건부인 경우 전투상황을 명시하며, 향후 새로운 종류가 현재 원형에 구현된 것처럼 표기하지 않는다. 테스트에서 입력 상태·RNG·코어·상자 개수 불변성 검증.

## 변경하지 않은 것
- 16종 유물 상한, 드롭률, 중복 시 지급 크레딧, 실제 전투 수치, 소집/보급/훈련 비용, 코어 적립·귀환 보상, 자동 소집·상자 개봉 간격, 저장 키, 공개 `main`은 그대로 유지.
- **장기적인 새로운 수집의 고갈 문제는 여전히 존재한다.** 3회차 뒤 콘텐츠 부족을 숫자로 해결하는 대신 실제 플레이에서 2~3번째 귀환 리듬의 질을 본 다음, 탐사 구조에 맞게 새로운 유물 깊이·조건부 능력을 추가할지 결정한다.
