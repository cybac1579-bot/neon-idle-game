# 《네온 방치단》 재설계 방향 — 실제 52~87 STAGE 기록 기반 (2026-11-17)

> **상태: 설계 제안 / 사용자 최종 승인 전.** 이 문서는 플레이 데이터에 따른 판단 근거 및 다음 대화의 의사결정 초안이다. 현재 코드 변경, 재설계 확정, 기존 기능 삭제 승인 또는 자동 개선 작업 전환 지시가 아니다.

## 1. 사용자 진술을 기반으로 한 목적 재정의

- 기존 UI가 완성된 게임보다 **여러 기능을 보여주는 시연 웹사이트**처럼 느껴진다. 문제는 화면뿐 아니라 기능들이 하나의 게임으로 이어지지 않는 체감이다.
- 사용자는 **《환생용병단》(Rogue with the Dead)**을 실제로 장기간 재미있게 플레이했다. 가장 기억에 남는 재미는 **유물 수집**에 가깝고, 중단 원인은 게임의 매력 부족이 아닌 적극적인 반복 조작에 들일 시간의 부족이었다.
- 최초 《네온 방치단》의 영구 레벨은 단일 공격 캐릭터가 아니라, **전투 캐릭터와 분리된 플레이어 자체의 레벨**이라는 의도가 있었다.
- 지향점은 완성된 게임 하나의 **전투→파밍→성장→환생 플레이 구조를 참조 원형**으로 삼아, 취향에 맞는 차별화 요소를 나중에 접목하는 것이다. 타 게임의 명칭/캐릭터/일러스트/코드/UI 고유 에셋을 그대로 복제해서는 안 된다.
- 모바일 Galaxy S25+ 세로 관전, 연타 공격 불가, 전투 메인 정보 최소, 세부 통계 별도, 고품질 도트 방향 검토 시 **《던전앤파이터》에 준하는 정교한 캐릭터/전투 애니메이션**이며 저품질 8-bit 대체가 아니다.
- 플레이 로그를 받기 전 제안했던 퀘스트 적립 용량 증가 및 무분별한 밸런스 수정은 보류한다.

## 3. 제안하는 단일 원형

**원형 후보 1순위: 《환생용병단》의 '전선 자동 전투→병종/퀘스트 경제→보스·보상 상자→유물 획득→플레이어 영구 성장과 환생→더 멀리 탐험' 루프.** 기존 게임을 그대로 클론하는 것이 아니라 **플레이 경험의 연결 방식**만 재구현한다.

핵심 차별화 원칙:
1. **플레이어 영구 레벨·특성**은 전투 캐릭터와 분리한다. 경험치는 전투/탐험 성과로 쌓고, 플레이어가 병종·유물·전략을 관리하는 영구 주체이다.
2. **부대가 싸운다.** 방치 관전이 중심이고, 근접/원거리/지원 중 소수의 역할로 시작한다. 액티브 탭 공격은 없다.
3. **유물 발견이 핵심 동기**다. 보스/탐험 보상 상자, 영구 도감·최초 발견 연출, 반복 획득의 사용처를 제공한다. 소규모 퍼센트 누적형만으로 도배하지 않고 일부 유물이 병종·전투·경제 규칙을 눈에 띄게 바꾸게 한다. 영구 수치 폭주를 막기 위해 누적 상한/분류를 둔다. *영구 효과/회차별 효과 혼합 여부는 아직 제안 단계*.
4. **자동화는 잡무를 처리한다.** 기초 퀘스트 회수와 반복 강화가 처음부터 지나친 수동 숙제가 되지 않도록 설계하되, 어떤 병종/유물/전략을 키울지와 환생 시점은 플레이어의 선택으로 남긴다. 기존 '첫 환생 후 자동구매 연구' 규칙과의 충돌은 재설계 승인 시 명시적으로 정리해야 한다. 임의로 기존 시스템에 바로 반영하지 않는다.
5. **환생은 목적이자 수단:** 반복 플레이로 유물을 얻을 기회가 열리고 영구 코어를 획득·투자한다. 기존 확정 '환생 횟수 자체는 보너스 없음', '전투·경제·자동화 투자 루트는 최종적으로 모두 구매 가능'을 보존한다.
6. **기존 확정 슬롯·계승 규칙 보존 검토:** 플레이어 LV10/25/40/60 장착 스킬 +1, 최대 5; 환생 스킬 계승 1~2, 계승 스킬 레벨 리셋. 단, 단일 주인공 스킬이 아닌 부대 전술로 의미를 재해석할지 별도로 검증한다.
7. **메인 UI는 전투와 발견 중심**으로 고정. 상세 수치는 별도 탭. 게임의 전체 톤과 연출을 먼저 통일하고 고품질 도트 여부는 실제 부대 전투 한 장면으로 판단한다.

### 최소 첫 통합 플레이 루프 제안

- 부대 역할 3종(근접·원거리·지원), 보스 1종, 전선 구간, 적·재화 드롭, 퀘스트 수익
- 발견할 유물 약 10~12종(기본/전략 변경형 혼합), 보상 상자, 도감, 최소한의 반복 수집 처리
- 플레이어 영구 레벨 및 소수 특성, 한 번의 재구성/코어 투자, 기존 스킬 장착/계승 규칙 일부 이식
- 전투 화면/부대 성장/유물 도감/플레이어 성장 네 묶음 이내 UI. 게임 저장/복원/오프라인/플레이 로그 유지
- **하지 않을 것:** 새로운 별도 재화, 월드 다수, 이벤트, 과도한 유물 종류, 초기부터 전체 고품질 캐릭터 일러스트, 수백 개 메뉴, 동일한 수치 시뮬레이션 반복
- '최적 플레이 첫 환생 약 60분'은 기존 임시 목표로 유지하지만, 새 게임 루프에서 먼저 **첫 20~30분의 완결된 발견/보상 경험**을 검증하고 실측으로 다시 맞춘다.

## 4. 이관 우선순위 (제안)

- **보존:** 실제 동작이 검증된 저장/복원·오프라인 정산·자동 전투 시계 및 전투 검증 도구·기기 로컬 플레이 로그·안전한 공동 개발 브랜치, 플레이어 레벨/특성 구조, 코어 재화와 환생 숫자 자체의 무보너스.
- **개념은 유지하되 구현 교체:** 단일 캐릭터 공격/무기 → 부대 전투와 병종 성장; 스킬을 부대 전술로 재검토; 정기 퀘스트/경제를 유물·모집의 동력으로 연결; 공격력/공속/발전기 버튼 과밀을 역할별 성장 UI로 묶는다.
- **나중에:** 위상 전환, STAGE180 이상 콘텐츠, 고품질 전체 도트 에셋, 미세 경제 60분 교정, 방대한 자동화 연구 분기, 신규 병종 대량 확장.
- **변경 승인 전 금지:** 현재 게임 코드/메인 배포 무단 대규모 수정, PR #2 병합, 검증 없는 '고품질 도트가 빠르다' 주장, 수집 원형과 무관한 새 시스템 추가.
