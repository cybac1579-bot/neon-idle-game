# 네온 방치단 — 중복 유물 실제 전투 체감·상자 보상 표시 감사 (2026-11-18)

## 이 작업의 목적
- 이전 36회 탐사 감사에서 45→50→55거리 3회차의 평균 중복 **12개**(상자 10, 정보망 2)가 누적되었으나, 해당 복제가 매번 새로운 전술 행동을 발생시키지는 않는 것으로 확인했다.
- 수치적 효과가 실제 전투에서 발생하는지 검증하되, **새 능력 발동을 만들어낸 것처럼 속이거나 전투를 무조건 가속하지 않는다**.
- 공개 `main` 보호, 모바일 세로 화면/관전 유지, 별도 상세 도감에서만 수집 설명 표시. UI/엔진 원형은 같은 개발 브랜치에서 교체 가능하도록 유지한다.

## 180초 실제 엔진 전투 비교
- `tests/expedition-relic-visible-combat-audit.cjs` 및 `.github/workflows/expedition-relic-visible-combat.yml`을 만들었다. 9종의 복제 가능 유물을 대상으로 현재 1개/2개/최대 상한을 비교.
- 전선은 동일한 방벽병 4·사수 3·정비사 2, 훈련 7, 지휘관 15, 지휘 특성 3, 전투 코어 6의 **인공 동일 편성**. 다른 모든 유물은 1개씩 보유. 적/시간은 35거리 정예, 50거리 보스, 60거리 보스 체력 45%의 3조건 × 180초. 자동 구매/코어 지출/자원 획득 조작 없음.
- 각 조건에 동일한 엔진 `tick`을 적용하고, 실제 가한 누적 피해, 유닛 전투 가능 시간/후퇴 횟수, 정밀사격/긴급회수 발동, 관전자에게 보이는 마지막 전투 신호 유형을 집계한다. **인간이 실제 관전하면서 즐거움을 평가한 테스트는 아니다.**
- 측정:
  - 용광로 문장 1→2: 세 조건 전부 실제 누적 피해 **+6.780%**, 새 전투 신호 횟수는 변하지 않음.
  - 초점 조준기 1→2: 35 정예 **+10.749%**, 50 보스 **+8.772%**, 60 보스 후반 **+10.721%**. 기존 세 번째 사격의 피해량이 달라지지만 추가 사격 횟수/새 행동을 만들지는 않음.
  - 균열 렌즈 1→2: 35 정예 **+0%**, 50 보스 **+12.281%**, 60 보스 후반 **+12.275%**. 조건부 보스 전용.
  - 재생 결속선 1→2: 회복·생존 타이밍 차이가 나타나며 누적 피해도 조건별로 달라짐. 조건 차이를 무시하고 단일 DPS 배율로 단정하지 않음.
  - 합금 배지/호위 계약서는 이 시험의 180초 동안 부대의 후퇴·유효 피해량이 달라지지 않았으며, 이것만으로 방어 효과가 없는 것으로 결론내리지 않음. 정예/보스의 피해·전열 대상/장기전을 달리하여 후속 검증 필요.
  - 교역 인장·탐사 일지·중복 해체권: 강제 자동 구매/새로운 조사/레벨 특성 투자가 없는 전투에서는 **직접적인 피해 증가 0%**가 정확한 정상 상태.
- 위 180초에서는 모든 실험이 동일 대상의 격파 완료 시각을 얻지 못해, 위 값은 **유효 누적 피해/가시 신호 비교이지 처치시간 단축율이 아니다**.

## 구현된 피드백 개선
1. 기존 `openChestBatch` 결과에서는 `permanentBonuses`의 일반 화력/체력/보급만 표시되므로, **지휘급 전용 피해·정밀 사격 추가 피해·정비사 회복·경험치 효과는 실제 개선돼도 0%p처럼 오해할 여지**가 있었다.
2. `rollRelic`은 기존 실제 추첨을 **완료한 뒤**, 해당 결과의 수집 직전 복제 수량으로 `nextRelicCopyPreview`를 한 번만 계산한다. `result.copyGain`은 보상 결과 표시용 일시 데이터라 저장 구조나 유물 획득 RNG를 바꾸지 않는다.
3. 상자 개봉/묶음 개봉 팝업에서 각 보상에 '이번 1개 효과 · 현재값 → 다음값'을 붙였다. 예: 보스 전용 균열 렌즈가 1→2→3개 연속 나오면 **보스 공격 보정 14→28%**, 이어서 **28→42%**. 고유 유물과 모든 종류 상한 교환도 구분한다.
4. 요약문을 '주요 상시 효과 변화 (조건부 효과는 유물별 표시)'로 변경했다. 보스 전용 유물만 얻은 팝업에 '상시 화력 0%p'로 표시되더라도, 그 이유와 조건부 보정이 보이도록 수정.
5. 기존 `expedition-field.js` 정밀 일제사격 하나의 전투 텍스트에 `정밀 사격 +90% · -피해량`처럼 **실제 수집한 사격 추가 피해 보정**을 표시. 새로운 버튼/별도 HUD/전술 발동 횟수를 추가하지 않았다.
