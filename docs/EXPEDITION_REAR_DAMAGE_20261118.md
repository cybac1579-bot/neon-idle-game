# 독립 용병단 — 방벽병만 피격되는 현상 확인과 후방 피격 보정 (2026-11-18)

## 사용자 실제 플레이 피드백
- 관찰: "방벽병 말고는 데미지 안받는거 같은데?"
- 근거: `site/expedition-engine.js`의 기존 `fight()`은 생존·전장 진입한 개별 용병들 중 **방벽병 → 척후사수 → 현장정비사** 고정 우선순위로 **한 명**을 선택하여 적 피해 100%를 입혔다. 방벽병이 한 명이라도 전선에 있으면 후열 체력이 거의 줄지 않는 것이 설계 동작이었다.
- 평가: 탱커의 우선 피격 자체는 의도된 역할이지만, 후열 병종이 사실상 무적처럼 보이면 병종별 체력/피격/회복의 가치가 불명확하고 전투 관전 피드백도 약해진다. **재현된 게임 로직 문제**이며 사용자 관찰이 맞다.

## 수정한 메커니즘
- 방벽병은 계속 적의 주된 공격 대상이다. 전열이 붕괴하면 살아 있는 다른 병종이 다음 공격 대상이 된다.
- 후열에 살아서 전장에 진입한 척후사수·현장정비사가 있으면, 적 공격 중 일반 8%, 정예 14%, 보스 22%를 **후열에 도달할 수 있는 몫**으로 계산한다.
- 한 명의 후열 병종이 과다 피해로 즉사해 진행이 무너지는 것을 막기 위해, 해당 후열 용병 최대 체력의 **일반 4%/초 · 정예 6%/초 · 보스 8%/초**를 1초당 피해 한도로 둔다. 후열 한도를 초과하는 공격력은 전열에 돌려준다. **전체 적 DPS를 새로 추가하지 않으며** 기존 적 피해 총량을 분배한다.
- 실전 후열 피격 대상은 3초 간격으로 살아 있는 후열 개체를 순환한다. 전장에 나온 병종 기준으로 처리하며 추가 난수 호출이 없어 기존 유물 등급 추첨 순서를 변경하지 않는다.
- 후열이 아예 없을 때 적의 모든 공격은 기존처럼 전열에 간다. 누가 쓰러지든 기존 개별 후퇴/6초 복귀/회복/피격 통계 규칙을 그대로 따른다.
- **용병 탭 설명과 피격 통계 이름도 수정:** 방벽병은 피해 대부분을 흡수, 척후사수·현장정비사는 후열에서도 피격 가능. 기존 `방어` 라벨을 `피격`으로 바꿔 실제 받은 피해 의미를 드러낸다.
- 실제 영구 성장, 코어, 환생 재화, 유물 드롭률, 저장키 `neon_expedition_prototype_v1`은 변경하지 않았다.

## 자동 검증과 회귀 비교
- 유닛 테스트 `tests/expedition.test.cjs`: 일반 14거리, 정예 15거리, 보스 20거리에서 방벽병·척후사수·현장정비사 피격 여부 및 전열 우선순위, 적 피해 총량 보존, 후열이 없는 경우의 기존 방식, 모든 방벽병이 후퇴했을 때 후열 피격을 검증.
- 30분 균형 자동 시뮬레이션에서 후열 피격 통계가 실제로 양수임을 확인. 영구 유물 수집/환생 행동은 기존대로 별도 사용자가 수행해야 함.
- **중요한 보정 과정:** 최초 단순 비율 분배(후열 HP 제한 없음)는 장기 45~50거리 단계에서 후열 사망이 너무 잦아 시드 2개의 균형 자동 모드 2회차 50거리 돌파가 15,000초 이내에 실패했다. 따라서 후열 최대 HP 비율 상한을 함께 적용함.
- 동일 코드 기반의 수동 재현 시뮬레이션(30초 축약이나 체감 평가가 아닌 실제 엔진의 1초 tick) 결과: 기본형 대비 HP 상한 적용 시 **3개 시드 × 2개 자동 구매 전략** 모두 1회차 45거리 → 환생 후 2회차 50거리 성공; 두 번째 50거리 걸린 시간은 균형 자동 **10,868 / 12,987 / 12,234초**, 적응형 **4,775 / 4,609 / 4,719초**. 기준 규칙(후열 추가 피해 없음)의 각각 **10,870 / 13,358 / 12,243초**, **4,777 / 4,610 / 4,719초**와 크게 다르지 않음. 다양한 조합·실제 사람 사용에서는 추가 검증 필요.
- 9초 고정 전투 14/15/20거리 시나리오에서 전열 전체 피격이 후열 합계보다 크고, 두 후열 병종 모두 피격되며, 총 피해량은 원래 적 총 DPS와 같음을 검증한다.

## 사용자 테스트 파일 갱신 주의
- 사용자가 현재 로컬에 저장한 **기존 `neon-expedition-offline.html`은 자동 업데이트되지 않는다**. 개선된 코드를 적용하려면 GitHub Actions에서 성공한 새 `neon-expedition-offline-playable` 아티팩트 또는 현재 대화에서 제공받은 **새 버전 파일**을 열어야 한다.
- 기존 진행 상황을 유지하려면 교체 전 **도감 → 전체 저장 백업**에서 `neon-expedition-full-save-YYYY-MM-DD.json`을 만들고, 새 파일의 **도감 → 저장 파일 복원**에서 불러오면 된다. 파일명이 같아도 브라우저의 `file://` 저장 공간 공유를 보장하지 않는다.
- 실기기 Galaxy S25+에서 후열 체력 바가 실제로 소폭 줄고 재생하는지, 자주 쓰러지지 않는지, 전투 긴장감이 개선됐는지는 아직 실제 플레이 피드백이 필요하다. 후열 병종이 방벽병과 동등하게 피해를 받는 구조는 아니다.
