# 독립 용병단 — 첫 번째 행동 변화형 유물 실험 (2026-11-18)

## 목적과 근거
- 사용자 실제 2회 귀환 기록과 피드백: 수집한 유물이 대부분 숫자만 변화시키고 전투·탐사 활동은 같아서 반복적으로 느껴짐.
- 현재 공개된 15종 유물을 무작정 추가하는 대신, **이미 사용자가 가지고 있을 수 있는 두 유물의 실제 전투 행동을 교체**해 짧은 테스트에서 차이를 확인한다.
- 이 실험은 최종 유물 디자인/아트/인터페이스의 확정이 아니고, 다른 유물·장비·탐사 콘텐츠로 확장할지 여부도 정하지 않았다.

## 실제 구현
1. **초점 조준기** (\`archer\`, 15거리 상자): 수집 수마다 사수 평타 +15%의 평탄한 증가에서, 사수 **매 3번째 공격마다 기본 피해에 +45%/수집 개수**가 붙는 정밀 일제사격으로 바꿈. 3회 평균 화력은 기존 +15%/개와 동일. 난수 없음. 개별 사수의 공격 카운트 \`shots\`는 0..2로 제한하고 저장/복원한다. 실제 적에게 준 추가 **유효 피해**(오버킬 제외)를 계산해 카운터에 적립한다. 일반 공격과 구분되는 전투 텍스트 \`정밀 사격!\`을 발동 시 표시한다.
2. **재생 결속선** (\`medkit\`, 15거리 상자): 기존 정비사 회복력 +18%/개 유지. 살아서 전열에 진입한 정비사가 있을 때 방벽병이 후퇴하면 **18초에 최대 1회**, 기존 6초 재합류 시간이 수집 개수마다 **1.2초 단축**(최저 1.2초). 즉시 부활, 후퇴 무효화, 자동 조작 추가는 하지 않는다. 전투 텍스트 \`긴급 회수!\` 및 상세 로그. 해당 조건을 충족하지 않거나 공용 쿨다운이 남으면 기존 6초를 그대로 사용한다.
3. **관전/통계**: 특별 이벤트 \`volley\`/\`triage\`는 전투 시각화에서 표시하고, 유물 탭의 세부 기록에는 이번 탐사 발동 횟수/추가 유효 피해를 표시한다. 전투 메인 화면에 새 통계 카드나 별도 버튼을 추가하지 않는다. 사용자가 요청할 때만 내보내는 플레이 기록 JSON에 이번 탐사 카운터를 별도 필드로 보관.
4. **기존 저장과 환생**: 저장키 \`neon_expedition_prototype_v1\`과 버전 1 유지. 오래된 저장에는 새 카운터/공격 카운트가 없으므로 0으로 복원. 보유 중인 두 유물을 새로 뽑지 않아도 변경된 전술 효과 즉시 적용. 귀환 시 유물 보유량은 유지하고 이번 탐사 발동 카운터와 단기 쿨다운은 초기화. 이전 판 \`neon_rework_07\`에 쓰지 않음.
5. **임시 UI 교체성**: 게임 로직은 \`site/expedition-engine.js\`, 시각 효과는 \`site/expedition-field.js\` + 임시 스킨 \`site/expedition-ui.css\`, 상세 수치는 \`site/expedition-ui.js\`에 분리. CSS·DOM 교체 시 효과 데이터는 그대로 유지.

## 자동 검증과 실제 표본 범위
- 새 단위 테스트: 3번 공격 중 3번째 추가 피해 및 평균 화력 유지, 중간 저장 후 정확한 3타 발동, 미보유 시 발동 0회, 정비사 생존 조건, 재합류 시간 제한/18초 공용 대기, 구 저장 누락 필드 복원, 귀환 시 카운터 초기화/유물 계승.
- 실제 \`ExpeditionEngine.tick()\`으로 opt-in 균형 자동 구매 + 매 300초 상자 수동 개봉을 가정한 **30분×3 시드**를 기존 엔진과 같은 규칙으로 비교:
  - Seed 123456789: 40거리 → 40거리, 두 대상 유물이 없어서 전술 발동 0.
  - Seed 987654321: 40거리 → 40거리, 새로운 사수 정밀 일제사격 2,507회, 추가 유효 피해 약 33,155, 응급 재합류 77회.
  - Seed 20261118: 40거리 → 40거리, 메디킷 보유/사수 유물 미보유 상태에서 응급 재합류 74회.
- 표본 3개, 균형 자동 구매 모드 한정. 직접 사람이 느끼는 전투 가독성, 초반 정체, 전체 환생 목표시간을 검증했다고 주장하지 않는다. 장기 45~50거리 비교와 다른 구매 전략은 CI 회귀·후속 실험이 필요하다.
- 기존 수치형 유물 다수는 **여전히 행동 변화를 만들지 않는다**. 이번 단계는 구조 가능성을 확인하는 수직 슬라이스이며 문제 전체를 해결한 최종 콘텐츠로 보지 않는다.
- 사수 3연사 리듬은 공격할 적이 한 명뿐인 기존 전투에서 추가 전술 선택지 없이 피해 모양만 변화시키므로, 장기 재미 개선 효과는 실제 플레이로 다시 검증해야 한다.
