# 《네온 방치단》 50거리 보스 장기 정체 수정 및 조기 귀환 전략 재진단 (2026-11-18)

## 목적과 우선순위
새 유물/기능은 추가하지 않고, 직전 **45~50거리 자동 구매 정체** 완화 이후에도 남은 50거리 보스 장기 관전 문제를 수정했다. 「첫 귀환은 최적 플레이 약 60분」 목표는 아직 실제로 달성하지 못한 것으로 구분한다. 유저가 강제 시간 제한이나 환생 횟수 자체 보너스를 원하지 않는다는 기존 결정 유지.

## 원인 재측정
조건: 동일 난수 시드 123456789 / 987654321 / 20261118, 자동 구매는 유저가 켰다고 가정, 상자는 5분마다 수동 개봉, 첫 탐사 45거리 적 격파→수동 귀환→코어 전선 투자→둘째 탐사 50거리 보스 적 격파.
- 직전 구매-공백 개선 이후에도 50거리 보스 한 마리의 **실제 공격 체력 소모** 시간이 일반 균형 957 / 953 / 893초, 유동형 1008 / 1021 / 960초였다. 성장 구매 간격 420~660초와 별도로 **15~17분 보스 한 명을 계속 공격**해야 하는 상황.
- 기존 50거리 보스 HP 971,759, 당시 용병단 표시 기초 화력은 약 900~1,100 DPS. 적 체력이 계속 줄어들기 때문에 전투 중단은 아니나, 관전형 진행에서는 사실상 긴 단조로운 구간.
- 50거리 앞선 일반 전선은 각각 수분 이내 진행; 보스가 상대적으로 긴 벽을 형성했다.

## 코드 수정 — 50거리 이후 보스만
- 50거리부터 10단위 **보스 체력 배수를 3.8×에서 2.2×로 완화**. 일반 적/정예 적의 수치 및 1~49거리의 모든 적(10·20·30·40 보스 포함)은 그대로 유지. 50거리 보스는 여전히 앞선 49거리 일반 적보다 체력 약 2.60배.
- 50거리 보스 최대 체력 **971,759 → 562,597** (약 42.1% 감소), 보스 보물 상자·기록 코어 5개·유물 「원정 연대기」 획득 조건·적 처치 코어 누적 공식은 변경 없음.
- 60, 70, 80, ... 거리 보스도 같은 배수 조정. 이후 거리의 실제 플레이 시간까지 전부 검증되었다는 의미는 아님.
- `site/expedition-engine.js`의 `enemyMax(stage)` 에 해당 조정을 적용; 새 콘텐츠 추가 없음.

## 실측 시뮬레이션: 동일 시드 교차 비교
| 모드 | 기존 50 보스 전투(초) | 수정 후 50 보스 전투(초) | 두 번째 원정 50거리 격파 총 시간(수정 후) |
|---|---|---|---|
| 일반 균형 balanced | 957 / 953 / 893 | **571 / 563 / 526** | 3336 / 3372 / 3268초 |
| 유동형 adaptive | 1008 / 1021 / 960 | **589 / 601 / 567** | 3301 / 3311 / 2948초 |
| 장기 저축 reserve | 원래도 매우 느린 구조 | 1489 / 1610 / 1522 | 7783 / 9209 / 9255초 |

**일반 균형·유동형은 보스 단독 전투가 약 8분 46초~10분 1초**까지 감소. 그래도 짧지 않으므로 실플레이에서 계속 관전할 만한지 검증할 필요. 장기 저축은 의도적으로 용병과 훈련에 덜 투자하므로 50거리 전투가 약 25~27분 계속되며, 이를 일반 모드와 억지로 같은 시간에 맞추지는 않았다.
이 전투 시간은 사람이 보스 전투를 체험하며 측정한 값이 아니라 엔진의 결정론적 계산.

## 중요한 저장 복원 호환성
- 기존 저장 중 50거리 이상의 보스 전투를 진행 중이면 기존 HP 절댓값을 단순 유지하지 않는다. 그러면 수정한 새 최대 체력보다 적 HP가 더 높게 표시되거나 기존 전투 진행이 무효화될 수 있다.
- `bossHpBalanceVersion:2`를 새 상태에 추가. 과거 버전(해당 마커 누락)의 저장은 **당시 보스 HP의 남은 비율**을 새 HP 최대치에 한 번만 반영한다. 예: 이전 보스 체력 40% 남음 → 새 보스 체력도 40% 남음.
- 다음 저장/복원 시 마커 2가 있으므로 반복 보정하지 않으며, 일반 적·정예·49거리 이전 적은 변경하지 않는다.
- 과거에 제작된 구버전의 보스 체력 기본 곡선은 마커가 없을 수 있다. 이번 보정은 **직전 체력 공식 3.8× + 40 이후 증가율 1.18**을 기준으로 한 보존이며, 훨씬 오래된 미기록 구버전 저장의 정확한 HP 비율까지 추정하지는 않는다.
- 게임 전체 저장 스키마 `VERSION=1` 유지; 기존 `main`이나 기존 게임 저장 키 불변.

## 초반 환생 경제: 더 세밀한 반례 확인
- 1시간 동안 10거리만 반복해 귀환하는 실험은 27코어/시간에 27번 수동 귀환해야 하며, 35거리까지 돌아 귀환하는 비교는 37~47코어/시간에 3~4번 귀환했다. 따라서 **10거리만 반복하는 극단적 농사**는 이 실험에서는 우월하지 않다.
- 그러나 **딱 한 번 일찍 귀환**해서 전선 코어에 투자하고 다시 45거리까지 탐사하는 하이브리드 전략은 별개다! 유동형 자동 구매에서 45거리까지 총 시간:
  - 무귀환 3361 / 3257 / 3530초 (56~59분)
  - 10거리 한번 귀환 후 3126 / 2991 / 3154초
  - **25거리 한번 귀환 후 2428 / 2552 / 2600초 (약 40~43분)**
- 따라서 **'최적 플레이의 첫 귀환이 약 60분'** 목표는 아직 미충족일 가능성이 높다. 이 사실을 반복 조기 귀환 효율이 낮다는 수치로 가리면 안 된다.
- 이 회차에서 조기 귀환을 강제로 막거나 보상을 근거 없이 하향하지 않았다. 우선 원정 전체 이익(기록 코어·보유 유물·성장 투자·전체 시간)을 기준으로 다음 밸런스 조정이 필요하다.
