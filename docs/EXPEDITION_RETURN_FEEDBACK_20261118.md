# 독립 용병단 탐사 — 환생 체감과 2회차 성장 비교 (2026-11-18)

## 목표
《네온 방치단》의 새로운 저조작 용병단 원형에서 '환생이 다음 판의 출발을 실제로 강화했는가'를 직관적으로 보이게 한다. 환생 직후 핵심 메시지는 전투 HUD가 아니라 간결한 결과창에 표시한다. 기존 `main` / `site/index.html` / `site/game.js` 및 구 게임의 저장키는 수정하지 않는다.

## 이번 구현 (기준 브랜치)
- `site/expedition-engine.js`:
  - `runOpening`: 매 탐사 **첫 출발 2명 무훈련 편성**의 초당 화력, 최대 체력, 1회 기본 보급 수익을 저장한다. 새 프로토타입 저장의 첫 시작은 용병/의뢰 원본 설정에서 계산하며, 이후 환생은 실제 전투 엔진의 `partyDps`, `maxHp`, `questIncome`으로 계산한다.
  - `latestReturn`: 최근 귀환 회차 번호, 실제 격파한 거리(현재 enemy stage−1), 격파 적립 코어, 1회성 최초 돌파 보너스, 유물 종류/복사 수, 남아 있던 미개봉 상자와 **이전 출발 → 새 출발** 스냅샷을 기록한다.
  - 영구 데이터의 저장/정규화는 기존 키 `neon_expedition_prototype_v1` 안에서 버전 유지. 이전 저장에 `runOpening`이 없으면 **과거 출발값을 추측하지 않고** 보고서의 비교 대상은 `null`로 남긴다. 다음 탐사부터 실제 출발 스냅샷이 생긴다.
  - 코어 수급량, 적 체력, 장비/유물 확률, 환생 해금과 리셋 규칙은 이번 작업에서 **수치 변경 없음**.
- `site/expedition.html` + `site/expedition-app.js`:
  - 귀환 확인 후 중앙 결과창에 이번 코어, 영구 유물, 화력/체력/경제의 두 회차 기본 출발값과 상대 증가율을 표시. '전선에서 이어가기'와 '영구 강화 확인' 중 선택해 이동. 세부 지표는 전투 HUD에 상시 노출되지 않는다.
  - 도감 탭 '최근 귀환 결과'에 동일 비교를 보존해서 나중에 다시 확인 가능. 잘못된/옛 저장은 기록 없음으로 표시한다.
  - 게임 플레이 정보를 사용자가 **직접** JSON 내보낼 때만 `latestReturnComparison`과 `currentRunOpening`을 파일에 추가. 네트워크 업로드/분석 없음.
  - 가시 전투 화면은 350ms 주기로 엔진에 맞춰 갱신하고, 비전투·정보 탭은 목록 DOM을 약 1.2초 주기로 갱신해 반복 작업을 줄인다. 버튼 조작·탭 이동은 즉시 다시 그린다.
- 테스트: `tests/expedition.test.cjs`의 숫자 보존·영구 증가·과거 저장 정직성·저장 복원·비정상 입력 방어; `tests/expedition-browser.test.cjs`의 360/390/412px 실제 Chromium 결과창, 다음 화면 이동, 리로드 보존, 데이터 내보내기.

## 실기기 20–30분 수동 검증 계획
1. 현재 경제 규칙이 실제 반영된 신형 미리보기인지 코드 SHA/버전을 확인한다. 이전 pinned Preview `c8bd6bc2`에는 환생 새 경제나 이번 결과창이 없으므로 **버전이 다르면 테스트 결과를 혼동하지 않는다**.
2. 용병단 자동 전투를 관전하고, 유물 상자를 적어도 1개 획득해 직접 개봉한 다음 도감의 해당 유물 성능 차이를 확인한다.
3. 10거리 보스를 넘어 코어가 누적되면 귀환을 선택하고 결과창에서 전후 출발 화력/체력/보급을 비교한다. 자동 전투가 다시 시작되는지 확인한다.
4. '영구 강화 확인'을 선택해 도감으로 이동하고, 원할 경우 보유 코어를 투자한다. 다시 전투로 돌아가서 두 번째 탐사를 관전한다.
5. 페이지를 새로고침하고 도감의 최근 귀환 결과가 유지되는지 확인한다. 브라우저 배경/잠금 후 돌아와 오프라인 정산을 확인한다.
6. 기록 분석을 원하면 도감 탭의 JSON 내보내기 버튼을 직접 누른 뒤 파일을 ChatGPT에 첨부한다. 어디가 지루했는지, 유물 발견/반복 귀환의 동기는 어땠는지 주관적 소감도 함께 남긴다.

## 검증과 남은 위험
- 자동화/시뮬레이션과 브라우저 에뮬레이션은 **실제 Galaxy S25+ 사용감, 웹뷰 스로틀링, 배터리/발열, 20~30분의 즐거움**을 보증하지 않는다.
- 신규 결과창은 한 번 더 닫거나 버튼을 누르는 단계이므로 **귀환 직후의 피드백 개선 vs 조작 피로 증가**를 실제 사용자 플레이로 확인해야 한다.
- 코어 투자 시 즉각적으로 증가하는 현재 전투력은 `전투/도감`의 실시간 수치가 반영하지만, 귀환 결과 카드의 '직후 출발값'은 **환생 버튼을 누른 순간의 고정 스냅샷**이다. 이후 수동 코어 투자까지 카드 수치를 덮어쓰지 않는다.
- 이전에 Vercel Preview 새 빌드가 일일 API 한도로 차단되었으므로, 검증된 새 코드가 실제 공개 URL에 반영되었다고 추정하지 않는다. 테스트 링크의 HEAD를 별도로 확인하고 공개 게임 교체/병합은 하지 않는다.
