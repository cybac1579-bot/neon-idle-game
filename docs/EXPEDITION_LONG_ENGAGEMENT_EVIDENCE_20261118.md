# 네온 방치단 — 1분 이상 장기 교전 실측·플레이 기록 (2026-11-18)

## 결정
- 30분·120분 대조에서 단일 교전이 최대 **1,157초**(19분 17초)까지 지속된 사례가 있다. 이 숫자는 **정해진 전술/자동화/시드의 인공 탐사** 수치이며 Galaxy S25 Plus 실기에서 느끼는 재미나 불편을 나타내는 수치는 아니다.
- 귀환하지 않고 계속 진행하면 성장 속도가 자연스럽게 느려질 수 있으므로, **모든 장기 교전에 자동 가속·추가 보상·재화 획득을 붙이지 않는다**. 그런 변경은 환생을 선택하는 의미와 수집·경제 밸런스를 무너뜨릴 수 있다.
- 대신 기존 메인 전투 화면을 복잡하게 만들지 않고, **귀환 상세 탭**에서 교전 시간을 눈으로 확인한다. 대상 적 거리, 관측된 교전 시간, 남은 체력 비율, 해당 교전 중 자동 구매 횟수, 이번 탐사에서 1분 이상 걸려 격파한 적 수, 완료된 최장 교전을 보여준다.
- 수집/진척 비교를 위해 탐사 기록에서 55/60/75/100거리까지 격파 시각을 조회할 수 있다. 미격파는 미격파라고 표시한다.
- 자동 개발/수동 개발은 동일 작업 브랜치 `integration/reconcile-main-redesign-20261114`만 사용. 공개 `main`에는 변경 없음.

## 엔진·저장·환생 규칙
- `site/expedition-engine.js`: 적 1명 단위 `engagement`에 관측된 `seconds`, 거리 `stage`, 교전 시작 시 자동 구매 누적 횟수, `legacyResume` 여부 저장. 적 격파 후에만 `longestEncounter`와 `longEngagements` 갱신. 60초 미만 격파는 장기 교전 횟수에서 제외.
- 적 보상 공식, 전투 피해량, 코어 적립/환생 지급, 자동 구매/개봉 간격, 16종 영구 유물의 드롭 확률은 **전혀 변경하지 않음**. 오래 버티는 것만으로 유물·코어·크레딧 보상 발생하지 않음.
- 백업/복원 시 현재 전투 경과와 완료 최장 기록 보존. 옛 저장에는 과거 교전 경과가 없으므로 **0초부터 관찰**, `legacyResume` 텍스트로 누락 범위를 명시. 허구의 과거 교전 데이터를 만들어 넣지 않음.
- 귀환 시 현재 탐사 교전 통계 초기화, 직전 귀환 결과 `latestReturn`와 최근 귀환 이력 `runHistory`에는 최장 완료 교전과 60초 이상 격파 수 보존. 기존 5개 이력 상한 유지.
- `site/expedition-app.js`: 사용자가 직접 내보내는 로컬 플레이 기록 JSON에 `currentEngagement`, `longestCompletedEngagement`, `completedFightsOverOneMinute`를 추가. 자동 서버 전송 없음.
- `site/expedition-ui.js`: 전투 메인에 새 버튼/상시 수치 노출 없이 귀환·탐사 기록 탭에서만 조회.
