# 《네온 방치단》 귀환 후 신규 유물 목표 수정 및 50거리 경로 비교 (2026-11-18)

## 이번 작업에서 해결한 표시 오류
이전 귀환 화면의 `다음 새 유물 등급`은 현재 탐사의 `stage`로만 계산했다. 영구 유물을 40거리까지 개방하고 귀환하면 `stage=1`이 되면서 이전에 개방한 15거리 등급을 다시 "다음 새" 등급으로 표시하는 잘못된 안내가 생겼다.

`site/expedition-ui.js`의 귀환 상세 계획을 **`lifetimeCleared=max(0,best-1)`** 기준으로 변경했다.

- 현재 회차의 `runBest`가 아니라 **영구 누적 최고 격파 기록**보다 높은 유물 등급만 "다음 신규 유물 개방"으로 나열한다.
- 예시: 누적 45거리 격파 후 귀환 → 다음 신규 유물 **50거리 · 원정 연대기**. 15/25/40거리를 새 등급이라고 반복 표시하지 않는다.
- 아직 개방하지 않은 카탈로그 종류 수를 함께 보여주어, 이미 개방한 등급의 **미획득 유물**과 아직 한번도 도달하지 못한 **새 등급**을 구분한다.
- 전부 깊이 개방했으면 "공개된 유물 N종 모두 깊이 개방"으로 안내한다. 이미 다 수집했다는 뜻은 아니다. 카탈로그 개수는 하드코딩하지 않고 `E.RELICS.length`에서 계산한다.
- 별도 메인 HUD 버튼이나 UI 고정 규칙을 추가하지 않았다. 임시 인터페이스에서 제공하는 자료이므로 향후 전체 UI 교체 가능.
- 새 게임 경제, 코어 가격, 유물 드롭률, 영구 유물 계승, 환생 조건/저장 키에는 변경이 없다.

브라우저 회귀 `tests/expedition-browser.test.cjs`에 독립 360/390/412px 문맥에서 **깊이45 격파 후 귀환 저장**을 주입하고, 신규 목표에 50거리 연대기가 나타나는지, 15거리 유물이 다시 신규로 보이지 않는지, 가로 넘침이 없는지 검사했다.

## 25거리 조기 귀환의 전체 목적지 재확인
기존 감사에서는 첫 45거리까지의 시간만 비교했다. 이번에는 **두 전략 모두 50거리 보스를 실제 격파**할 때까지 계속 추적했다.

- **직진:** 45거리 격파 → 수동 귀환·코어 전선 투자 → 50거리 보스 격파
- **조기:** 25거리 격파 → 수동 귀환·코어 전선 투자 → 45거리 격파 → 두 번째 수동 귀환·전선 투자 → 50거리 보스 격파
- 시드 `123456789,987654321,20261118` × 균형/유동 자동 구매 × 상자 자동 개봉 OFF(5분마다 유저가 개봉)/ON(60초 자동 개봉), 총 **12쌍, 24번의 원정 경로**. 전투를 탭하여 빠르게 하는 조작은 없다고 가정.
- 동일한 50거리 목적지에서 모든 비교쌍의 영구 전선 코어 레벨은 **9**. 모든 비교쌍의 서로 다른 유물 종류는 **15종**. 누적 유물 복사본 개수가 차이.
- 조기 귀환이 **12쌍 중 11쌍**에서 빨랐고, 평균 속도 이득은 **13.75%**, 최대 **26.3%**. 딱 한 조건에서 직진이 빨랐다.
- 조기 경로는 5거리마다 획득하는 상자 **24개**, 직진 경로 **19개**. 실제 보유 유물 복사본은 조기 경로에서 평균 **5.67개** 더 많았다.
- 45거리 한 번 귀환 시 코어 **60개**, 25거리와 45거리 두 번 나눠 귀환하면 **5+57=62개**를 받는 샘플이었다. 이 둘은 반드시 최종 영구 코어 레벨/잔여 코어와 구분한다. 첫 번째 25거리 조기 귀환이 가진 5코어와 이른 영구 강화·유물 수집 기회가 복합적인 이점을 만든다.
- 이 수치는 시뮬레이션의 특정 플레이 정책 결과다. 이득 35% 이상을 회귀 경보로 삼았지만, 35% 이내가 재미있고 균형이 맞는다는 증거는 아니다.

`tests/expedition-stage50-two-routes-audit.cjs`를 새로 만들고 `tests/expedition-route-audit.cjs`에 연결. 모두 동일 엔진, 실제 원정 상태 전개/상자·전선 코어·보스 승리/수동 귀환 경로를 사용하며 단지 정적 코어 공식 비교에 그치지 않는다.

## 기존 CI 오류 관찰과 범위
앞선 커밋의 브라우저 통합 작업은 내부 엔진 테스트에서 실패했다. 원인은 신규 **측면 공격 전술**이 발동된 거리15/20의 후열 피해 비율을 예전 단순 14%/22% 상한으로 검사한 낡은 단언이었다. 자동 개발 쪽에서 단계15의 피격 비율을 수정된 전술 기준에 맞추었으며, 이 회차에서 최신 엔진으로 직접 재현한 평균 후열 비율은 거리14 **8%**, 15 **15.56%**, 20 **22.64%**였다. 이전 버전의 CI 실패를 최종 성공이라고 주장하지 않으며, 새 커밋 전체 CI를 재확인해야 한다.
