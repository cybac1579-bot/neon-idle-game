# 독립 용병단 — 일반 적 전투 변형 1차: 돌격병 / 철벽 진형 (2026-11-18)

## 결정 배경과 범위
- 2회 귀환 플레이 피드백에서 플레이어는 **유물의 숫자만 올라가고 계속 같은 전투를 관전**하는 점을 문제로 꼽음. 정예/보스의 '측면 조준'과 유물 '호위 역습'이 이미 구현되었으므로, 이번 단계는 **일반 적에도 구분 가능한 행동**을 넣어 수집·전술 다양성의 최소 구조를 검증.
- 전투 버튼/반복 조작/탭 액티브를 추가하지 않음. 현재 `expedition.html` 및 `expedition-ui.css`는 최종 UI 승인본이 아니라 **교체 가능한 임시 플레이 화면**.
- 이번 단계는 단일 일반 적 변형만 검증한다. 모든 거리의 적이 다양해졌다고 주장하지 않는다.

## 실제 엔진 규칙
1. `enemyKind(stage)`에서 정예/보스 우선, 8거리 이후 `stage % 6 === 2`인 일반 거리(예: 8, 14, 26, 32, 38, 44 등)는 **돌격병(`charger`)**. 적 체력, 크레딧, 상자, 귀환 코어 수식은 불변. 정예/보스 스케줄도 불변.
2. 돌격병이 최소 3초 생존하고 전장에 살아 있는 방벽병이 배치되면 **1.5초 돌진 예고**를 표시한다. 예고 종료 시 살아 있는 전열 방벽병 한 명의 전진 위치(`progress`)를 0.22 지점까지 밀어내고, 공격 간격을 최소 0.6초 남기도록 조정한다. 그 방벽병은 기존 이동 속도로 다시 전열에 합류한다. 한 적당 최대 1회이며 **추가 HP 피해/랜덤 드롭/과도한 행동 방해를 발생시키지 않는다**.
3. 영구 유물 **합금 배지(`shield`) + 진군 북(`swift`)**를 둘 다 보유하고 전장에 방벽병이 있으면 **철벽 진형** 활성화: 돌격 밀치기를 무효화하고 방벽병이 한 번 자동 반격한다. 실제 적 체력/유효 피해/전투 기여에 반영. 유물의 기존 체력 +10%/개, 화력 +5%/개도 그대로 적용.
4. 적 행동은 `enemyTactic.kind/elapsed/phase/windup/used/result/flash`로 저장·복원한다. `relicEffects.rushes/braces/braceDamage`는 이번 탐사 통계로 누적하고, 귀환 이력 스냅샷에 보존한다. 기존 저장에서 필드가 누락되면 합리적인 초깃값으로 정규화하며 **과거 횟수는 소급하지 않는다**. 사용자 저장키 `neon_expedition_prototype_v1`과 예전 `neon_rework_07` 불변.
5. `site/expedition-ui.js`에서 적의 종류(돌격병, ♞)와 합금 배지+진군 북 조합 해금/성과를 표시. `site/expedition-field.js`에서 실제 1.5초 경고 → 충격/진형 유지 텍스트. 임시 스타일은 `site/expedition-ui.css`. UI를 추후 교체해도 엔진/저장·전술 상태를 유지한다.

## 자동 테스트
- `tests/expedition.test.cjs`: 일반 적/돌격병/정예/보스 종류 분기; 돌격 경고와 실제 한 명의 가드 후퇴; 예고 도중 저장 복원; 적당 1회 제한; 합금 배지/진군 북 유물 2개 모두 필요; 추가 HP 피해가 없는지, 방어·반격의 실제 적 체력 감소; 귀환 이후 이력 보존과 과거 저장 기본값.
- `tests/expedition-browser.test.cjs`: 360/390/412px의 실제 관전 고정 화면에서 엔진 시뮬레이션으로 발생한 돌격 예고와 철벽 진형을 가시화하고, 유물 탭을 열고 있어도 전투 장면이 존재하는지 확인.
- 엔진 `ExpeditionEngine.tick()` 비교: 새 전술 이전 `49101e8bd4fda54de491fb93b6e7b4a890bf146c` vs 신규 브랜치. 균형형 자동 구매와 자동 상자 개봉을 모두 켠 상태로 `30분/120분 × 3개 시드 × 보유 기본값 또는 합금 배지+진군 북 임의 소지` **12쌍** 실행.
  - **전부 기존과 같은 도달 거리/귀환 코어량/유물 종류 개수**. 30분 돌격 발동 4~5회, 120분 5~6회. 합금 배지+진군 북을 임의로 선지급한 샘플에서는 돌격을 모두 막았으며 소량의 실제 반격 피해 추가.
  - 선지급은 조합 효과를 분리해 검증하기 위한 가정으로, 일반 플레이에서 실제 획득 시점/확률을 입증하는 결과가 아님.
  - 기존 보유 유물을 그대로 둔 3개 시드 중 우연히 두 유물을 모두 수집하는 경우도 있어 일부 자동 저지됨.
- 실기기 Galaxy S25+ 관전 체감, 시각적 만족도, 게임을 길게 할 동기는 추가 사용자 피드백이 필요. **하나의 돌격형을 더한 것으로 반복감이 해결되었다고 주장하지 않는다.**

## 이어서 볼 설계 문제
- 일반 적 전술은 매우 한정된 거리에만 나오고, 오래 살아남아야 경고까지 실제로 발동하므로 진행 초반에서는 주로 종류/외형 차이만 보일 수 있다.
- 다음은 돌격병 외 원거리·회복 방해 등 **전투 역할이 구분되는 종류**나, 새로운 유물 조합/선택지의 수집 가치가 충분한지 검증하는 편이 단순 공격력 배율 증가보다 우선한다.
- 사용자가 원하는 것은 전투가 항상 관전 가능한 게임. 전투 화면과 성장 화면을 다시 배타적 탭으로 나누지 않는다.
- 개발은 통합 브랜치 `integration/reconcile-main-redesign-20261114`만 수정. 공개 `main`/기존 웹 게임 미수정. 현재 실행 중인 HTML 자동 패치되지 않으며 교체 전 전체 저장 백업(JSON) → 새 HTML 복원이 필요하다.
