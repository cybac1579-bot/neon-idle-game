1. 폰 세로로 /expedition.html 입장 후 전투원 이동이 눈에 잘 들어오는지 확인.
2. 별도 행동 없이 3–5분 관전 → 용병 탭의 성장 방향을 1개 선택해 자동 구매 켜기. 원하면 수동 강화와 비교.
3. 5거리/10거리 상자가 생기면 단일 개봉과 도감의 모아 열기 비교. 첫 발견·중복의 기분과 영구 강화 정보 가독성 확인.

6. 관전 중 지루했던 시점, 유물 획득의 동기, 다시 환생하고 싶은지, 조작 피로가 남는지를 짧게 주관적으로 평가. 플레이 데이터를 자동 전송하지 않음.
