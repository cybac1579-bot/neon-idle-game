# 《네온 방치단》 지휘관 영구 특성 재분배 지원 (2026-11-18)

## 발견한 기능 누락
독립 원정 원형에는 지휘관 영구 레벨과 두 가지 특성(전술 통솔: 공격력 +6%/레벨, 보급 지휘: 보급 수익 +8%/레벨)이 이미 있었지만, **레벨업으로 획득해 투자한 특성 포인트를 되돌리는 수동 기능이 없었다.**

이 때문에 한 번 전투/경제 쪽에 투자하면 반복 원정에서 다른 전략을 시험할 수 없었고, 플레이어의 장기적인 빌드 탐색 목표와 맞지 않았다. 이번에는 새로운 특성 종류나 재화를 추가하지 않고 사용자의 투자 자유를 복구했다.

## 실제 구현
- `site/expedition-engine.js`: `respecTraits(s)` 추가 및 공개. `command + supply`에 실제로 투자한 **포인트만 두 특성에서 0으로 돌려놓는 함수**. 반환값은 되돌린 포인트 수. 투자한 포인트가 0이면 `false`이며 상태를 변경하지 않는다.
- 미사용 포인트는 **기존 공식 `heroLevel - 1 - (command + supply)`** 에서 산출되므로 영구 지휘관 레벨·경험치/유물·코어·기존 귀환 기록이 모두 유지된다. 게임 시작 시 자동 초기화하거나 환생 시 강제 초기화하지 않는다.
- `site/expedition.html`의 **용병단/지휘관 성장 세부 패널**에만 `특성 포인트 재분배` 버튼과 영구 자원 유지 안내 추가. 전투 HUD/메인 화면에 새 통계/버튼을 추가하지 않는다.
- `site/expedition-app.js`: 사용자가 버튼을 직접 눌렀을 때만 재분배하고 즉시 기존 로컬 저장/화면 갱신 경로 실행. 자동 구매·상자 자동 개봉·오프라인 정산 등 다른 시스템은 해당 명령을 호출하지 않는다.
- `site/expedition-ui.js`: 되돌릴 특성이 없으면 버튼 비활성화.
- 기존 특성 구매 상한(두 종류 각 10레벨), 기존 레벨업/특성 수치 및 환생 보상·코어 가격·유물 드롭률/전투 HP 불변. `VERSION=1`, 저장키 `neon_expedition_prototype_v1` 유지.

## 검증

- `tests/expedition.test.cjs`에 새 테스트 연결.
- `tests/expedition-browser.test.cjs`: 360/390/412px 별도 세이브에서 지휘관 LV8/기존 투자 3+2를 주입해 미사용 2포인트→재분배 후 7포인트 확인, 코어 11/유물/전선 코어 불변 확인, 다른 특성 1포인트 재투자 후 6포인트 확인. 화면 가로 넘침도 기존 검사 그대로 적용.
- 기존 저장·첫 환생 밸런스·3회 원정·오프라인 단일 파일 모바일 브라우저 CI는 새 커밋 기준으로 계속 실행한다.

## 후속 설계 판단
- 재분배는 재화를 소비하지 않는 **명시적 수동 선택**이다. 특정 교전에서 공격/보급 간 효과를 바꾸는 전략적 활용도 가능하지만 전투 연타 입력, 자동 귀환, 자동 배분이 추가되는 것은 아니다.
- 현 원형의 두 특성만을 대상으로 하며, 새 특성이나 제한·비용을 추후 추가할지는 실제 플레이에서 선택의 재미와 마찰을 평가한 뒤 결정해야 한다.
- 유일 작업 기준 `integration/reconcile-main-redesign-20261114`, 기존 `main`과 기존 게임 저장은 건드리지 않았다.
